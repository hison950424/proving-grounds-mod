# 版本號說明

## 格式

測試版使用 **`0.主要.次要`**，第一碼固定為 0，正式版時才改成 1。

版本號只存在一個地方：`gradle.properties` 的 `mod_version`。jar 檔名、`mods.toml`（透過 `${file.jarVersion}`）、
遊戲內顯示（主選單右下角、`/pg status`）都從它取得，由 `tools/release.ps1` 更新。

| 這次更新內容 | 改哪一碼 | 例 |
|---|---|---|
| 新增系統或玩法、改變玩家操作方式、改動存檔或設定檔結構、移除功能 | 第二碼加 1，第三碼歸 0 | 0.2.0 → 0.3.0 |
| 修錯誤、調整數值、翻譯、貼圖、效能優化、小幅 UI 修改 | 第三碼加 1 | 0.2.0 → 0.2.1 |
| 一次包含多項不同大小的更新 | 以其中最大的那項為準 | |

拿不準時往小的算；但只要會讓舊存檔、設定檔、伺服器與客戶端版本不相容，一律算大更新。
