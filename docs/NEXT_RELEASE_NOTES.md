### 修復
- **修復半磚走上 1 格方塊與連續上兩階半磚卡住的問題**（`SlabRampShapes`）：改為低端前 0.5 格平滑爬升、後半 0.5 格保留平坦頂部平台，讓半寬 0.3 格的玩家碰撞箱在接觸下一階前已穩站頂部高度，不再因高度差超過 0.6 卡牆。
- **修復團隊死鬥／佔點玩家倒地後自然流血（或放棄）死亡未計擊殺的問題**（`ArenaDowned` / `ArenaManager`）：最終死亡前強制清除無敵幀並保留擊倒者歸屬，流血致死、長按 F 放棄或環境補刀皆 100% 計入擊倒者擊殺、分數與獎金。

### 調整
- **取消團隊模式套用大逃殺移動速度（保留跳躍規則）**：團隊死鬥不再套用 `BRMovement` 的降速移動倍率，維持原版＋職業移動速度，跳躍高度與取消疾跑前衝規則保留。
- **全面升級「倒地／擊殺／助攻」旗幟與音效（Apex／三角洲爽感＋高區別性）**：
  - 大逃殺與團隊模式擊倒敵人時皆顯示專屬橘金色向下箭頭「擊倒／爆頭擊倒」旗幟並播放破甲碎盾＋頓點音效。
  - 擊殺改為鮮紅／爆頭金色雙刃交叉戰術旗幟，搭配厚實低頻重擊＋雙層高亮金屬鐘鈴音效（連殺音階上升、爆頭加破甲高音，整體音量提高更清晰）。
  - 助攻採用青藍色十字星旗幟與輕快清亮雙音，三者視覺與聽覺徹底區分。
- **團隊死鬥與佔點新增助攻（50%）與擊倒（25%）收入，並平衡佔點戰鬥／站點經濟（`_v2`）**：
  - 團隊死鬥與佔點：助攻獲得擊殺獎金的 `50%`，開啟倒地時擊倒敵人獲得擊殺獎金的 `25%`。
  - 佔點模式（DOM）：擊殺獎金由 `12 → 60`（對應助攻 `30`、擊倒 `15`）、首殺額外獎金調整為 `120`（合計 `180`）、據點站點每秒收入由 `2 → 5`（站滿 13 秒 `65`），保留原本回合勝敗與金錢上限框架。
- **團隊死鬥階段比例改為 20% 前期／30% 中期／50% 後期並平衡金錢倍率（`_v3`）**：
  - 階段切換點由 `33% / 67%` 改為 `20% / 50%`（10 分鐘場為前 2 分鐘前期、2～5 分鐘中期、5～10 分鐘後期）。
  - 基礎獎金調為擊殺 `35`、陣亡補貼 `25`、落後補貼 `10`，階段倍率調整為 `×1 / ×2 / ×4`（擊殺獎金依序 `35 / 70 / 140`，助攻減半 `17 / 35 / 70`），進入中期／後期落後隊伍補貼同步微調為 `600 / 1200`。
- **全模式倒地血量與流血調整（`_v2`）＋團隊模式長按 F 放棄**：
  - 所有模式倒地血量改為 **`50 HP`**、每秒流血 **`0.5 HP`**（流血總時間維持 100 秒，補刀更俐落）。
  - 團隊模式倒地時可 **長按 `F` 3 秒**（顯示即時進度條）選擇放棄並直接死亡進入重生，擊殺照常歸屬給擊倒者。
- **團隊死鬥特殊道具改為充能與重生補給制**：死亡後重生給予 1 個特殊道具；擊殺敵人充能 **1 格**、助攻充能 **0.5 格**，充能滿 **2 格**自動給予 1 個特殊道具，每次給予道具後一律從充能 `0` 開始重新計算。
- **團隊死鬥重生點保護二樓可見＋每張場地獨立圓形／方形與大小**：
  - 修復防蹲點紅牆高度與高度判定（紅牆改為 `y-4 ~ y+20`、高度判定放寬至 `±16` 格），二樓與高台也能清楚看到敵方重生區邊界。
  - 支援每張團隊場地獨立選擇 **圓形（`circle`）或方形（`square`）**；方形保護支援 **紅隊／藍隊各自獨立調整北（-Z）、南（+Z）、西（-X）、東（+X）四邊長度**（管理員面板內附一鍵「東西鏡像／南北鏡像→另一隊」），並獨立儲存至該地圖（黑曜地堡預設採用方形）。
- **裝備抗彈率平衡微調（`v5`）**：小幅拉開中高階甲體感（皮革／海龜 `8%`、鎖鏈／金 `12%`、鐵 `18%`、鑽石 `28%`、獄髓 `36%`）。
- **奔跑時可立即開槍並瞬切擺正槍口（開鏡仍強制切走路）**（`TaczInstantFire` / `ClientMovement`）：消除 TACZ 奔跑收槍延遲（`sprintTimeS`），奔跑中按左鍵可零延遲開火，並於開槍瞬間將奔跑歪槍動畫（`run` / `run_end`）0 秒瞬切回正對前方的 `idle` 姿勢且短暫鎖住自動奔跑（300ms），避免槍身未擺正就射出子彈；奔跑中按右鍵開鏡依然強制切換為走路模式。
- **團隊死鬥與佔點玻璃可破壞並自動復原**：
  - **團隊死鬥（TDM）**：子彈與近戰皆可打破玻璃，每一塊被打破的玻璃於 **10 秒後**獨立自動復原。
  - **佔點模式（DOM）**：子彈與近戰皆可打破玻璃，每回合開始時自動復原全部被破壞的玻璃。
