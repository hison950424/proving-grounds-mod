### 趴下動畫重製與四肢／持槍 Hitbox 全面對齊（v0.33.1）

- **重製陸地趴下與爬行動畫**：修正原版趴下第一幀先垂直插進地板再慢慢躺平的問題，改為貼地平滑前傾趴下與起身，任何過渡幀都不會穿地；並取代原版在水裡的蛙式划水動作，改為低姿匍匐爬行與趴下持槍瞄準姿勢。
- **趴下身體即時跟著視角轉向**：取消原版視角轉超過 ~45° 才帶動身體轉向的延遲，趴下時轉動滑鼠身體立刻跟著轉向（伺服器端判定也同步）。
- **修復走路四肢 Hitbox 擺動方向相反**：改用與原版 Minecraft 渲染完全相同的 `Matrix4f` 變換鏈與樞軸算式，確保走路／跑步／蹲下／揮擊時手腳判定框與實際人物動畫方向 100% 一致。
- **修復趴下／站起過渡期間 Hitbox 瞬間切換**：Hitbox 改依 `swimAmount` 平滑曲線逐幀插值（伺服器與客戶端過渡速度同步），不再在按下趴下／站起瞬間直接瞬切。
- **修復持物、持槍與趴下爬行 Hitbox 不符**：同步支援手持一般物品、舉盾／拉弓／望遠鏡／長矛等使用動作、TACZ 第三人稱持槍與開鏡角度、開傘舉手，以及趴下爬行與趴下持槍姿勢；客戶端 F3+B 判定框與伺服器命中／防具部位判定全部共用同一套算式。
