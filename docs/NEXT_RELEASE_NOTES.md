### 修正與調整
- 比賽中也可以調整 HUD：大逃殺大地圖（M）上方、團隊模式商店底部多了「HUD 設定」按鈕。
- 修正子彈彈道常常消失：優化模組 Entity Culling 會把又小又快的子彈當成「看不到」而不畫，已把 TACZ 子彈、手榴彈、特殊物品投擲物列為一定要畫（客戶端模組包的設定）。
- 降落傘：自己第一人稱改用沒有傘繩的傘衣模型，傘繩不再擋住視野（別人看你照舊有傘繩）。
- 圈外傷害的受傷聲音量降低 75%。
- 大逃殺爆炸物（RPG、榴彈、手榴彈等）會炸毀地圖範圍內的方塊，大廳可以設定開關（「炸毀方塊」，預設開）。箱子、祭壇、墓碑不會被炸掉，被炸掉的方塊不掉落，比賽結束自動還原。
- 補品、投擲物的專用格（第 4、5 格）已經有別的物品時，在物品欄 Shift 點背包裡的補品／投擲物會直接互換（原本的放回背包），不再沒反應。
