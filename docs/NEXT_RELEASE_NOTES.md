### 新增
- **管理員大地圖支援直接切換預覽地圖**：管理員開啟大地圖（非對局中）時，上方工具列提供地圖下拉選單，可直接選擇任意一張已登記的大逃殺地圖切換預覽（即時同步俯視圖、復活祭壇、大區域名稱，並支援右鍵傳送與命名大區域）。
- **管理員控制台底部常駐「取消目前作業」按鈕**：任何分頁皆可於右下角即時一鍵取消進行中的建圖、光照修復、俯視圖繪製、團隊地圖生成或 marker 掃描作業。
- **獨立「修復無形方塊」功能（與光照修復分開）**：於控制台「大逃殺地圖」與「系統維護」分頁新增瞬間「修復無形方塊」按鈕，直接重送已載入區塊消除幽靈方塊／空氣牆，無需等待耗時的光照重算；「修復光照」則專注於重建天空與方塊光照。

### 調整
- **優化大逃殺三種縮圈預設的每階段縮小比例（`v4`）**：補上「準決賽圈」過渡，消除中大型地圖（500～700 格）最後直接從百格斷崖縮到 11.5 格的問題：
  - 快速：`0.52 → 0.24 → 0.09 → 0`
  - 標準：`0.62 → 0.36 → 0.18 → 0.07 → 0`
  - 慢速：`0.72 → 0.50 → 0.32 → 0.17 → 0.07 → 0`
  - 自訂方案維持獨立冪次曲線公式計算，不受影響。
