- **修復玻璃片／石牆／鐵欄杆／柵欄與樓梯轉角連接**：
  - 生成建築結束後自動執行兩輪鄰接形狀更新（`updateFromNeighbourShapes`，含由上往下第二輪確保多層石牆與大片玻璃幕牆完全連接），不再出現單根不連接的方塊。
- **修復多樓層樓梯最後一階被挖空**：

- **重製 4 種風格各 3 棟（共 12 棟）大型／超大型高物資豐富內裝建築（每棟 28～36 個物資點，全程禁用木箱）**：

  - **工業倉庫 (3)**：超大型貨運物流中心（39×29×17，34 點）、重工業煉鋼鑄造廠（35×29×22，32 點）、渦輪發電廠主機房（31×27×19，30 點）。
