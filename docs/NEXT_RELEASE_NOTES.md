### 新功能
- 標點：按 X（可以在按鍵設定改）在準星指的位置標點，自己和隊友看得到標點和「離自己幾公尺」，隔著牆也看得到。標點顯示 5 秒：前 2 秒清楚、後 3 秒半透明，之後消失；再標一次會取代上一個。不同隊看不到。
- TACZ 槍托近戰的按鍵從 X 改成 Y（第一次開新版時自動改；自己改過的不會被蓋掉）。
- 一行匯入地圖：`/pg map import auto <資料夾> <地圖名稱>`，自動偵測地圖大小、匯入、畫好小地圖與大地圖。

### 調整
- 防彈改成只算「被打中的部位」那一件防具：打頭只看頭盔、打身體或手看胸甲、打腳看護腿（腳的下段看靴子）。不會再把全身四件的護甲加在一起，耐久也只扣被打中的那一件。

### 移除
- 跑酷開始方塊、跑酷結束方塊（有嚴重 BUG）。地圖上已經放的會自動消失，上面的排行榜文字也會自動清掉。跑庫塔不受影響。
