- 修復部分建築窗戶玻璃片插到地底的問題（修正 `WildStructures` 窗戶座標參數與 `BuildingCanvas` 最低高度限制）
- 修復有海晶燈的建築會覆蓋吃掉樓梯的問題（天花板燈改為自動避開樓梯與上方通行淨空）
- 修復建築樓梯最底部沒有預留上樓空間的問題（樓梯入口前 2 格自動淨空並防止家具／物資箱堵路）
- 修復更改「藥水效果」HUD 位置後，按下 TACZ `Z` 鍵開啟槍械配件改裝畫面出現偏移無法使用的問題（開啟任何介面時暫停位移藥水效果並補齊矩陣還原保護）
- 修復團隊模式（死鬥／佔點／槍王）死亡等待重生時會有一瞬間閃回大廳的問題（死亡時將原版重生座標暫時鎖定於場內，重生後自動還原）
- 修正大廳全員皆已準備時不該再顯示「管理員強制開始」按鈕的問題，並區分自然全員準備與管理員強制開始的倒數副標題

### 新增
- 新增 **UI 圖文教學與道具圖鑑**（主選單首頁「圖文教學與道具圖鑑」按鈕，隨時可查閱）：
  - **圖文教學**：5 大章節（大逃殺流程、團隊模式玩法、操作與快捷鍵、特殊道具機制、管理員建圖工具），搭配真實物品圖示、按鍵徽章與戰術示意圖
  - **道具圖鑑**：收錄全模組基礎裝備、方塊、62 種特殊道具與 11 種管理工具，支援分類篩選與中英文即時搜尋
- 新增 **管理員控制台工具**（`admin_panel`，創造模式「Proving Grounds」分頁或 `/pg give tool admin_panel`）：右鍵一鍵操作生成 5 張大逃殺地圖、原地升級、光照陰影修復、生成黑曜地堡、重繪俯視圖、重載設定與取消任務
- 新增 **大地圖大區域命名功能**：建圖時自動套用各城區名稱；管理員於大地圖按右鍵可新增、修改或刪除區域名稱（亦支援 `/pg map label add|remove|list`）
- 新增 **團隊模式場地選擇器**：大廳設定頁的團隊死鬥／據點爭奪／槍王之王可直接切換「經典場地（設定檔）」或「黑曜地堡」等自訂團隊場地
- 新增 **背景作業即時進度條 UI**：所有非瞬間完成的建圖、原地重建、光照修復、俯視圖繪製、團隊地圖生成與 marker 掃描皆會在畫面上方顯示目前階段與百分比進度條
- 新增 **Windows 非打字時自動鎖定英文輸入法**（`WindowsImeLock`，聊天／告示牌／輸入框打字時自動恢復中文輸入法；可於 `config/provinggrounds-client.toml` 的 `[gui] ime_lock_enabled_v1` 開關）

### 調整
- 大廳預覽地圖同步顯示「重生祭壇」位置（紫色十字）與「大區域名稱」
- 開啟 UI 介面時同步支援 **靜走、蹲下、趴下**（原本僅支援方向鍵與跳躍）
- 大逃殺建築朝向改為四方向多樣變化，不再全部面向同一邊
- 擴充小房區建築由 8 種增至 **14 種**、野區微據點由 4 種增至 **8 種**、野外掩體增至 **8 種**
- 大逃殺小房區與野區改為「非均勻聚落分布」並適度降低總量，保留戰術留白與高張力熱點
- 優化大城區地板與道路生成：區域廣場邊緣與周邊地形自然漸層銜接，道路會止於城區與小聚落廣場外緣而不再直接插入地板
