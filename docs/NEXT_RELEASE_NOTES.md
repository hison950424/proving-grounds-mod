### 分身、介面操作、同步轉身、斷線無敵修復與對戰模式調整（v0.33.3）

- **分身不顯示頭頂 ID**：殘影分身與掉線分身一律隱藏頭頂玩家名稱標籤。
- **修復打開 UI 介面無法跳躍**：開啟商店、背包、大地圖等介面時，除了前後左右移動外，現在按空白鍵也能正常跳躍（打字輸入框與聊天畫面仍自動暫停接管）。
- **站立／蹲下／趴下全面同步轉身**：取消原版站立時頭轉超過 ~45° 才帶動身體轉向的延遲，站姿與蹲姿現在跟趴下一樣，轉動視角身體與 Hitbox 即時同步轉向。
- **修復玩家斷線重連後不受任何傷害**：
  - 修復在迷你死鬥等 PvP 場地斷線後場地紀錄被清空、重連後被誤判為安全區而無敵的問題（重連依位置自動還原場地）。
  - 修復大逃殺與團隊模式斷線重連時殘留 `invulnerable`／原版登入無敵保護時間／殘留無實體化與保護計時的問題，並補齊大逃殺回歸時重新登記遊戲與同步隊伍。
- **佔點模式死亡不噴裝也不產墓碑**：玩家在佔點回合中陣亡時單純清空身上裝備與背包（整場特殊道具保留），地上不會掉落任何物品，也不會生成墓碑。
- **全面移除 C4**：移除商店與語系殘留中的 C4 項目。
- **團隊死鬥／佔點禁止拾取非本職業槍械**：非本職業限定槍種的槍械掉在地上時無法拾取（自由人無限制）。
- **「槍戰對決」改名為「槍王之王」**：大廳與介面顯示名稱統一改為「槍王之王」。
- **槍王之王丟棄槍械規則**：現在可以丟棄手上的槍械，但丟出的槍**只有丟棄者本人能撿回**（其他人無法拾取）；身上沒有武器滿 **5 秒**後會自動補發目前階段的武器，並同步清除剛剛丟棄在場上的武器。
