### 調整
- 決賽圈擴大：決賽圈固定半徑由 `7.5` 格再增加 4 格為 **`11.5` 格**（直徑 23 格）
- 縮圈邊界平滑移動：縮圈期間提高伺服器邊界同步頻率並加入客戶端逐幀線性平滑插值（`ClientBRState.smoothCircle()`），世界白牆與大小地圖安全區邊界全程滑順收縮不再一格一格跳動
- 容器介面替換背包放回原容器：在箱子、物資箱、墓碑等其他物品介面以 Shift+左鍵直接拿取背包或拿取後點擊自己背包欄替換時，換下來的舊背包會直接放回該其他物品介面中（不再留在自己背包或掉在腳邊）
- HUD 介面設定側邊面板支援收起與展開（收起後僅在角落保留「展開設定／完成」按鈕，調整原本被面板遮住的 HUD 元件不再被擋住）
- 大地圖標題（含大廳「地圖預覽」名稱）移至地圖左側顯示，不再與上方「HUD 設定」按鈕重疊
- 5 張主題大逃殺地圖升級為三層高密度佈局（大幅改善空曠感）：
  - 在原有 4～9 個大城區之間自動補滿大量 **「第二層：小型衛星房區」**（新增 8 種無木箱 2 層民宅／加油站／碉堡／鐵皮倉庫／和風町家／農舍／沙漠院落／極地研究艙，每個聚落 2～3 棟＋院牆與鄉間支線小路）
  - 新增 **「第三層：野區戰術微據點」**（路障檢查哨、野戰營地、可穿行貨櫃堆、斷垣廢墟，每處含 3 個掩體旁物資點）
  - 野外掩體密度提高近 3 倍，改採 **成片樹林叢帶＋倒木、多格巨石／冰丘／砂岩柱群、長條戰術矮牆、軍車、沙包陣與貨櫃**
- 修復大逃殺 5 張新地圖部分區域地板殘留奇怪陰影／黑塊的問題（建圖與重建後會自動完整重建天空與方塊光照並同步給玩家；已生成的地圖也可直接用 `/pg map relight` 原地快速修好）

### 新增
- 新增 `/pg map relight [all|<地圖編號>]`（原地快速重建大逃殺地圖所有區塊的光照層，立即清除既有地圖上的殘留陰影）
- 新增 `/pg map generate regen`（自動原地升級重建先前已生成的 5 張同名地圖並更新物資點／祭壇／俯視圖；亦可指定 `/pg map generate regen <地圖編號> <預設>`）
- 新增雙層室內近距團隊地圖 **「黑曜地堡」(`obsidian_bunker`)**，適用於 **團隊死鬥、佔點模式與槍王之王**（走道最大 4 格寬、高密度沙包／機櫃／貨櫃／防爆牆掩體、4 座 3 格寬樓梯與 2F 環形天橋）：
  - 執行 `/pg arena map generate` 即可自動建造完成並直接啟用（紅藍各 3 個重生點、6 道基地屏障、佔點 `A/B/C` 三據點、44 個槍王重生點全部預先設好，無須手動調整設定即可直接開局）
  - 支援 `/pg arena map list`、`/pg arena map select <default|obsidian_bunker>`（保留原經典場地可隨時切回）、`/pg arena map tp [id]` 與 `/pg arena map regen`
