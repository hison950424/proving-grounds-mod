### 新增
- 一鍵生成 5 張區域密集主題大逃殺地圖（`/pg map generate`）：
  - 新增 5 張尺寸梯度地圖（半徑 **300 / 400 / 500 / 600 / 700 格**），每張具備鮮明區域分區與高密度街廓建築群（沿用 52 棟無木箱建築＋自動登記大量物資點）：
    1. `harbor`（`300` 格）：**鐵灣港城**（4 區、17 棟、5 座復活祭壇）
    2. `desert`（`400` 格）：**赤砂帝國**（5 區、22 棟、7 座復活祭壇）
    3. `arctic`（`500` 格）：**極光要塞**（6 區、30 棟、9 座復活祭壇）
    4. `imperial`（`600` 格）：**緋櫻古城**（7 區、38 棟、11 座復活祭壇）
    5. `continent`（`700` 格）：**萬象大陸**（9 區、55 棟、13 座復活祭壇）
  - 支援 `/pg map generate all` 依序全數建造並自動繪製俯視圖（或單張指定 `/pg map generate 300` 等），自動分配各區復活祭壇、放射／外環公路、跨河橋樑與野外戰術掩體
- 大廳大逃殺地圖預覽：大廳處於大逃殺模式時，所有玩家皆可從主選單（按 M →「預覽大逃殺地圖」或大廳分頁地圖設定下方）開啟目前選定大逃殺地圖的俯視預覽，查看地形與邊界範圍（支援滾輪縮放與左鍵拖曳）
- 管理員右鍵地圖傳送：權限管理員（OP）在大地圖或大廳地圖預覽任意位置按右鍵可開啟選單，點選「傳送到此處 (X, Z)」即可直接傳送至該位置地表上方（自動同步載入區塊並計算安全落地高度），亦提供「重設全圖視角」
