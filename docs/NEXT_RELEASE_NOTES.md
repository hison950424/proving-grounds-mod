- **修復背包已滿時按 Z 卸下槍械配件或裝卸彈匣退彈，物品跑進快捷欄專用格的問題**（`PlayerInventoryMixin` / `HotbarRules` / `HotbarEvents`）：攔截 `Inventory.add` 改走快捷欄規則，背包滿時卸下配件不會塞進第 1～5 專用格或鎖定背包格；卸彈退出的子彈若無合法空位則同 tick 即時整理或掉在腳邊並同步畫面。

### 新增
- **競技大逃殺全面改版：規則鎖定、戰術道具池分流與四排位段位積分系統**（協定版本 `36 → 37`）：
  - **競技規則鎖定**：切換至競技模式後固定為 **慢速縮圈（`SLOW`）**、**友軍誤傷開**、**全部爆炸破壞方塊**、**開啟戰術型特殊道具池**（`br:special_competitive`，過濾整人與過度誇張的道具，僅保留煙霧、雪牆、腎上腺素、致盲球、靜音靴、護甲修復、急救針、基礎／標準掃描器、各式地雷、毒氣彈、安全區庇護、誘餌、空投信標）。
  - **嚴格四排位滿員開局**：大廳可選 **單排（1 人）／雙排（2 人）／三排（3 人）／四排（4 人）**，單排禁止組隊，雙／三／四排每一隊皆須剛好滿編才可開始。
  - **競技淘汰直返大廳**：競技模式下孤狼死亡後、或有隊友的隊伍全滅後，直接還原狀態並送回大廳（防報點，本局結束仍會自動結算排位積分）。
  - **四種獨立排位積分（RP）與 7 段位**（`RankSystem` / `PlayerDataManager`）：青銅（0）、白銀（500）、黃金（1000）、白金（1600）、鑽石（2300）、大師（3100）、戰神（4000+），入場門票 `0 / -10 / -20 / -30 / -40 / -50 / -60`（含 1 場降段保護）；總隊數 `≥ 4` 隊為 `100%` 正常積分，`3` 隊 `75%`、`2` 隊 `50%`、`1` 隊不計分；新增 `/pg rank [玩家]` 隨時查詢四種排位段位與積分。

### 調整
- **雙端 32 區塊（512 格）實體追蹤／渲染鎖定＋TACZ 依槍種放大射程**（`EntityTrackingRangeMixin` / `EntityRenderRangeMixin` / `TaczRangeScaler`）：
  - 強制鎖定玩家與 TACZ 子彈實體的雙端追蹤與渲染距離至 **32 區塊（512 格）**。
  - 依槍種放大 TACZ 子彈最遠射程（保留原生傷害衰減與下墜）：狙擊槍／重武器 **`512 格`**、機槍 **`256 格`**、步槍 **`220 格`**、衝鋒槍 **`120 格`**、手槍 **`80 格`**、散彈槍 **`48 格`**。
- **團隊模式九大職業全面平衡＋投擲物攜帶上限（一般 3 個／支援兵 4 個）**（`ArenaClass` / `ArenaData` / `ClassCombatEvents` / `ArenaMode`）：
  - **突擊兵**：移速加成 `+20% → +12%`。
  - **自由人**：商店折扣 `8 折 → 9 折`（維持全武器解鎖）。
  - **重裝兵**：血量 `110 → 125 HP`、正面減傷 `-10% → -15%`、移速懲罰 `-15% → -10%`。
  - **狙擊手**：移除命中發光，改為 **擊殺／助攻／擊倒金錢 +30%**（發育加速）。
  - **偵察兵**：新增 **擊中敵人使其發光 0.5 秒**（隊友可見），自動掃描最近敵人冷卻 `20 秒 → 15 秒`（發光 1 秒）。
  - **醫護兵**：光環擴大為 `6 格`、回血 `1 → 2 HP/秒`，新增 **使用補品時間 -25%** 且 **用補品後 6 格內隊友同步回復醫護兵回血量的 50%**。
  - **支援兵**：投擲物攜帶上限 `4 個`（其餘職業上限 `3 個`）、重生直接贈送 `1 顆隨機投擲物`、陣亡後清空投擲物；每 `20 秒` 給予自己 `1 隨機投擲物＋1 醫療用品`，並給予 `6 格` 內隊友 `1 隨機投擲物或 1 醫療用品`。
- **攀爬精準高度判定（1.5～3.0 格）＋速度提升 50% ＋強化第一人稱撐起動畫**（`WallClimb` / `ClientWallClimb`）：
  - 依起跳地面高度判定，僅翻爬 `1.5 ～ 3.0` 格高方塊（1 格高方塊不再誤觸發）。
  - 翻爬時間由 `18 → 12 tick`（速度 +50%）、收手 `4 → 3 tick`，第一人稱改為更鮮明的三段「前伸扣牆 → 大幅下壓撐起 → 推離平台」雙手動作。
- **柵欄／石牆碰撞高度統一為精確每格 1.0 格**（`BlockCollisionMixin`）：將石牆矮段（原本 `0.875` 格）與堆疊兩層的柵欄／石牆碰撞箱一律對齊至每格 `0.0～1.0` 高度，可順利從 1 格高石牆／柵欄直接跳上 2 格高石牆／柵欄。
