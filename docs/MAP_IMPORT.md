# 匯入新地圖

伺服器開著就能做，不用關伺服器、不用動存檔檔案。

## 步驟

1. **準備地圖存檔**：把地圖的存檔資料夾（裡面有 `region` 資料夾的那一層）複製到伺服器根目錄的 `map_imports` 資料夾，例如：
   ```
   1.20.1 Proving Grounds_Server_Mod/map_imports/新地圖/region/r.0.0.mca
   1.20.1 Proving Grounds_Server_Mod/map_imports/新地圖/entities/r.0.0.mca   ← 有的話（畫、物品展示框、盔甲架）
   ```
   舊版本（1.12～1.19）的存檔也可以，匯入時會自動升級成 1.20.1 的格式。

2. **看範圍**（管理員）：
   ```
   /pg map import info 新地圖
   ```
   會列出存檔裡有方塊的範圍，並給一行建議指令。存檔周圍如果有很多自然地形，建議自己縮小半徑、改成地圖真正的中心（可以先在單人遊戲打開那個存檔，按 F3 看座標）。

3. **開始匯入**：
   ```
   /pg map import start 新地圖 <來源中心X> <來源中心Z> <半徑> <地圖名稱>
   ```
   - 自動找一個和現有地圖相距約 5000 格的空位，並對齊區塊。
   - 每個 tick 最多用 15 毫秒，伺服器照常可以玩；每 200 個區塊在聊天欄回報一次進度。
   - 整個區塊從最低到最高照來源覆蓋：目的地原本的地形會被清掉，箱子內容、告示牌、畫、展示框都會搬過來。
   - 做完自動登記成新的大逃殺地圖（`/pg map list` 看得到）。
   - 中途要停：`/pg map import cancel`（已經搬過去的區塊不會復原）。

4. **匯入後**：
   - `/pg map render <編號>`：產生小地圖、大地圖用的俯視圖。
   - 到地圖裡用 `/pg loot add <編號>` 設定箱子點位（站在要放箱子的位置執行）。
   - 想改名字、中心或半徑：`/pg map set <編號> <X> <Z> <半徑> <名稱>`。

## 限制

- 生態域（草地顏色、天氣、霧）不搬，用目的地原本的。
- 只搬主世界（`region` 資料夾），地獄和終界不搬。
- 大逃殺進行中不能開始匯入。
