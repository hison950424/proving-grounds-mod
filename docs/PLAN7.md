## A. 介面、流程與修復

### [x] A1. HUD 透明度：文字與背景分開調整
- HUD 介面設定裡，每個元件現在只有一個透明度。改成**兩個滑桿：「文字透明度」「背景透明度」**。
- 舊的單一透明度值遷移成兩個相同的值（存在每位玩家的 `config/provinggrounds-hud.json`，注意不要被舊檔蓋掉新欄位）。

### [x] A2. 管理員移除「開始」按鈕
- 大廳與大逃殺設定畫面裡，管理員的「開始」按鈕移除。
- 開始遊戲只剩兩種方式：**全員按準備自動開始**，或**管理員按「強制所有人準備」**。

### [x] A3. 全員準備與前置準備都直接倒數登機 10 秒
- 現在的流程：全員準備後倒數，之後還有一段「前置準備」（上飛機前的準備時間）。
- **我的解讀（請確認）**：**取消前置準備階段**。不論是全員準備或管理員強制所有人準備，都是同一個「**10 秒倒數 → 登機**」；倒數期間不受傷，結束就進飛機。
- 請在回報說明：原本的前置準備做了哪些事（例如補血、清背包、分隊鎖定、傳送），拿掉階段後這些事改放在倒數開始或登機的哪個時間點。

### [x] A4. 打開箱子的畫面改版
取代 v0.28.0 的「左邊箱子、右邊物品欄」：
- **背包部分要和單純開背包的畫面一模一樣**：含玩家模型、防具欄、背包欄、特殊物品欄、副手。
- **箱子在右側、玩家背包在左側**（和 v0.28.0 相反）。
- **如果可以，讓玩家自訂**打開箱子時「箱子」與「背包」各自的位置：在 HUD 介面設定新增這兩個元件，可拖曳，存同一個設定檔；畫面太窄時退回預設排版。
- 墓碑畫面（已是分區物品欄）一併套用同一套位置設定。
- 驗收：箱子畫面裡可以像背包畫面一樣把特殊物品放進特殊物品欄、穿防具；副手只是**顯示**，仍然只有系統能放（第四份的規則不變）。

### [x] A5. 修復：電梯方塊 BUG
症狀：(a) 在上方電梯蹲下，傳到下方，但**又被傳回上方**；(b) 有時**走到電梯方塊上方什麼都沒做就被傳走**。
- **先在遊戲裡重現並找原因，不要假設。**
- 我的懷疑（請驗證）：觸發用的是「持續狀態」而不是「按鍵剛按下的瞬間」，且傳送後沒有冷卻；傳到下方後蹲著的狀態還在，下方電梯又判成「蹲下」或讀到「跳躍」；(b) 可能是走上方塊時的高度變化或自動跳被當成「跳躍」。
- 建議修法：只在「蹲下鍵剛按下」或「跳躍剛起跳」那一刻觸發一次；傳送後冷卻 1 秒（設定值）；落點要求站在地面、上方有 2 格空間；被傳送者需放開蹲下再按才能再次觸發。
- 回報附實測紀錄。

### [x] A6. 修復：自訂縮圈的「預估時間」不會隨數值更改而變
- 大廳的自訂縮圈畫面，改階段數、每階段等待／縮圈時間、圈速度、開場等待、最後一圈大小、決賽圈時間後，**預估總時間要即時重算並更新**（含決賽圈）。
- 請先重現並找原因（懷疑：預估值只在開啟畫面時算一次，或讀的是舊的方案快取，沒讀自訂方案的即時值）；三個預設方案的預估也一併檢查。
- 驗收：每改一個數值，預估時間立刻變。

### [x] A7. 商店配件排列整理（讓畫面不那麼亂）
- **瞄具依倍率從小到大排**（紅點、全息等 1 倍以下放最前，再 2 倍、3 倍…到最高倍；同倍率依名稱或價格）。
- **其他配件相同屬性排在一起**：依屬性分組（槍口、握把、槍托、彈匣、雷射、其他…），同組內依價格或效果強度排；組與組之間留間隔或加小標題。
- 排序規則集中在資料產生工具（`tools/make_arena_data.py`）或載入端，不要手排。
- 「手上槍可裝的配件變色」（v0.28.0 已有）在新排序下要仍然正常。

### [x] A8. 商店防具：套裝格子＋一鍵購買整套
- 排列：**由左到右是材質**，順序依現有「防具照強度排」：皮革 → 鎖鏈 → 金 → 鐵 → 鑽石 → 獄髓；**由上到下是 帽、胸甲、褲、靴**。海龜殼不屬於套裝，維持單件放在最後，請回報你放哪裡。
- 每一欄（同材質）有一個「購買整套」按鈕。
- 整套價格預設＝四件價格總和（不打折；若覺得該折扣請在回報提出）；自由人八折照舊；錢不夠時按鈕灰掉並顯示差額。
- 已穿同部位防具時，整套購買對每一件套用現有單件購買規則（直接穿上／互換）；完成後顯示一行小字結果。
- 單件購買保留（點格子買一件）。

## [x] D. 補完：掉線分身（所有模式）

使用者已確認：帶裝備、被殺掉落、全模式；掉線在被系統移出前都算隊伍人數（`disconnect_timeout`，預設 300 秒）。
目標：玩家比賽中掉線時，在原地留下一個不動、可被擊殺的分身，避免「掉線躲死」。

### [x] D1. 分身實體
- 重用 `special/entity/DecoyEntity.java` 與 `special/client/DecoyRenderer.java` 的外觀處理（皮膚用 OWNER UUID、複製護甲與手持物）；新增分身模式（例如 `DisconnectBodyEntity` 子類別或 `mode` 旗標）：**不動、不跑、不自動消失、血量與掉線瞬間相同（含額外生命值）、受傷與死亡都是真的**。
- 外觀不可與真人有明顯差別；名條規則同真人（只有同隊看得到）；隊友可看到淡色輪廓（可選設定）。
- 不出現在地圖、不會被偵測器選為目標（或依設定）。
- **掉線當下若玩家正在倒地：分身維持趴下姿勢，流血計時繼續，隊友可用 F 扶起（已確認）**；若做不到請回報，退回「分身倒地計時，不可扶」。

### [x] D2. 狀態保存
- 掉線瞬間把玩家狀態存進 SavedData（`OfflineState`：UUID、隊伍、位置、血量、額外生命值、背包與裝備 NBT、金錢、職業、模式進度、掉線時間）。伺服器重啟後分身與狀態都能恢復。
- 同一玩家同時只有一個分身。比賽結束、`/pg reset`、`/pg arena stop` 時清掉所有分身與 `OfflineState`。

### [x] D3. 分身被擊殺
- 照一般死亡處理：掉落物品（大逃殺放進墓碑，用 `OfflineState` 的物品 NBT 建立；其他模式照該模式的死亡規則）、記擊殺者的擊殺與擊殺紀錄（擊殺圖示與紀錄對分身也有效）。
- 各模式後續：
  - **大逃殺**：該玩家淘汰，不復活（復活牌與祭壇規則同一般死亡）。
  - **團隊死鬥、槍王之王**：分身被殺 = 該玩家死亡一次（金錢、死亡數照常）；**玩家回歸前不重生**；回歸後走重生倒數 3 秒。
  - **佔點**：該回合視為陣亡，下回合開始時回歸者照常重發起始裝備。
- 實作提示：淘汰、擊殺、掉落流程目前以 `ServerPlayer` 為參數；離線時沒有。請抽出「不依賴玩家物件」的共用入口（以 UUID＋`OfflineState` 為輸入），**不要為了離線者硬造假 `ServerPlayer`**；改動範圍大，先列出受影響的函式再動手。

### [x] D4. 掉線時限與回歸
- 把 `disconnect_timeout` **擴充到大逃殺**：
  - 超時前回歸：分身還活著 → 分身消失，玩家回到分身的位置、血量、狀態繼續；分身已被殺 → 依 D3 的各模式規則。
  - 超時：玩家被移出比賽與隊伍（此時才從隊伍人數扣掉並重算槍王門檻）；**大逃殺超時視為淘汰**，分身消失，身上物品放進墓碑；其他模式分身消失（這些模式是 keepInventory，物品不掉落）。移出後回來只能旁觀。
- 通知（小字，符合提示不擋視野）：隊友收到「○○ 掉線」「○○ 回來了」「○○ 因掉線過久被移出」。

### [x] D5. 邊界情況
- 分身在未載入區塊：實體凍結；計時用伺服器遊戲時間，不依賴實體 tick；回歸時若實體不在已載入區塊，直接以 `OfflineState` 還原。
- 分身站在縮圈外：照一般規則受圈外傷害；**站在敵方重生區：防蹲點懲罰對分身適用（已確認）**。
- 特殊物品效果（隱形、無敵、護盾）掉線時結束；分身不繼承。
- 迷你死鬥、大廳、訓練場、跑庫塔：**不產生分身**。

## [x] E. 補完：團隊模式倒地開關（團隊死鬥、佔點、槍王之王；預設關）

- 大廳設定新增「倒地」開關（只有管理員可改，**預設關**）。重用 `modes/br/BRDowned.java`、`events/DownedEvents.java`、`special/ActionLock.java`；把 BR 專屬的假設（復活牌、祭壇、`BattleRoyaleMode` 的參賽者表）抽成共用介面，**不要複製貼上一份**。
- 規則（沿用 BR 的部分照現行；下列是團隊模式的差異）：
  - 致命傷時，若同隊還有至少一位**未倒地**的存活隊友 → 倒地；否則直接死亡。孤狼（槍王的單人隊）沒有隊友，直接死亡。
  - 倒地：移動速度、趴下、禁止使用物品、可開背包／丟／撿、可使用特殊物品（同 BR）；流血時間與扶起後血量沿用 BR 設定。
  - 扶起：同隊用 F，進度條中斷條件同 BR。
  - **擊殺計算**：倒地時擊殺紀錄顯示「擊倒」；**最終死亡時才計擊殺與隊伍分數**（TDM 擊殺數、金錢、槍王晉級擊殺都在最終死亡時結算）；被扶起則不計。
  - **佔點**：倒地的人算存活，但**全隊都倒地或死亡 = 全滅**，立刻全部死亡並判回合結束。
  - **槍王之王**：階段武器在倒地期間保留；晉級時整隊換武器，**倒地者也立即換（已確認）**。
  - 倒地者被殺或流血結束 → 一般死亡流程（TDM／GK 倒數 3 秒重生、佔點等下一回合）。
- 驗收：開關預設關時三個模式與現在完全一樣；開啟後兩人以上測試（可用 `/pg arena debug` 輔助）：倒地、扶起、全隊倒地判全滅、擊殺在最終死亡時才計入。

## [x] F. 補完：擊殺穿牆樣式

## 電腦端進度紀錄（做完一項寫一行）

- A5 電梯：原因（從程式推斷，沒辦法開客戶端重現）＝伺服器用「客戶端回報離地往上移動」猜跳躍（jumpFromGround → LivingJumpEvent），傳送後第一筆位置回報、自動跳躍、走上台階都可能被當成跳躍；冷卻只有 6 tick，網路延遲大就擋不住 → 傳下去又被傳回來、走上去被傳走。修法：改成客戶端 `ui/ClientElevator` 只在跳躍鍵／蹲下鍵「剛按下」時送 `ElevatorPacket`，伺服器再確認站在電梯上；冷卻 `elevator_cooldown_seconds`（預設 1 秒）；蹲下要放開再按。網路版本 22 → 23。
- A6 預估時間：原因＝客戶端用自己的伺服器設定副本算，那份只在登入時同步，大廳改自訂值後客戶端副本不會變。修法：伺服器用最新設定與目前地圖半徑算好，放在 LobbyStatePacket 的 customCircle[6]；三個預設方案也一樣改由伺服器算（含決賽圈）。
- B 決賽圈：`modes/br/Circle` 各階段改成「方案中大於 2.5 格的階段 → 2.5 格（最後一階段）→ 停留 → 0（決賽圈）」，決賽圈不算在階段數；設定 `fast/standard/slow/custom_final_hold_seconds_v1`（30／45／60／45），自訂可在大廳調，`/pg circle set <方案> final_hold <秒>`。決賽圈期間不掉空投（排定的取消）。HUD 標題顯示「決賽圈」。
- C 特殊物品：C1 假槍聲整個移除（物品、貼圖、語言、箱子、標籤、引擎 SpecialWorld.Gunfire 與 gunshot_* 設定；世界裡已有的假槍聲因為物品不存在了，載入時 Forge 直接移除）。C2 雷神錘半徑 20。C3 回溯點特效所有人看得到。C4 彈簧鞋 `spring_power_v2` = 3.9（原 1.3 的 3 倍）。C5／C6 失去方向感從毒氣移到洗腦（同一段 `ClientSpecial.onRenderTick`）。C7 急救針沒倒地時回 25 血（滿血時不消耗）。C8 多人跳傘半徑 5。C9 靜音靴 `silent_bonus_v1` = +100%，與刀、強心劑不疊加取較大者。C10 強心劑：**內部 ID 不改（仍是 adrenaline）**，所以箱子與身上舊物品不用轉換；使用時受 `stim_self_damage_v1`（10）傷害，但最多扣到剩 1 血（算上額外生命值）；`adrenaline_bonus_v2` = +50%；效果期間倒地 → 給「強心劑：倒地可行動」效果，時間 = min(5 秒, 強心劑剩餘時間)，從倒地那一刻起算（`stim_downed_free_seconds_v1`）；倒地時強心劑／靜音靴的速度不加成（倒地緩速照舊）。倒地不能回血的規則不變（可以用補品，但不會回血）。C11 雪牆與四種地雷可用 2 次（NBT `pg_uses`，名稱後面顯示 2／2、用過一次顯示綠色耐久條）；地雷沒有上限（移除 `mine_max_per_player`），偵測改每 5 tick 一次並錯開。
- A1 HUD 透明度：HudLayout 每個元件多一個 bg_alpha（舊檔沒有時等於 alpha）；文字與圖示用 setShaderColor，背景色塊由 `mixin/GuiGraphicsFillMixin` 乘上「背景 ÷ 文字」；HUD 介面設定選取元件後有「文字透明度」「背景透明度」兩列（背景最低 0%）。
- A2：大廳的「開始」按鈕拿掉；伺服器收到舊客戶端的 START 也拒絕並提示用準備／強制所有人準備。
- A3：前置準備原本做的事（`BattleRoyaleMode.start`）＝清背包（保留近戰）、清效果、補滿血與飽食、切冒險模式、同步隊伍、送地圖俯視圖、清掉上一局的空投／墓碑／特殊物品、還原並開始記錄方塊、分批刷新箱子；期間不受傷。現在大逃殺全員準備（或強制所有人準備）就直接開局，上面這些在倒數一開始做完，接著固定 10 秒「即將登機」倒數（不受傷），倒數完登機（登機時照舊再清一次背包、補滿血）。箱子還沒刷完會等它刷完才登機。團隊模式照舊是大廳 10 秒倒數。`lobby_countdown_seconds` 不再使用。
- A4 箱子畫面：`mixin/ChestMenuMixin` 在所有 ChestMenu 最後加上頭、胸、腿、腳、副手、背包欄、特殊物品欄（`block/ChestExtraSlots`，原本格子編號不變；副手照舊玩家不能放）。`ui/ChestSideLayout` 改成左邊背包（玩家模型、防具、背包欄、特殊格、副手，位置跟物品欄畫面一樣）、右邊箱子；兩塊的位置是 HUD 介面設定新的「箱子畫面（只能移動）」群組裡的「箱子畫面：背包」「箱子畫面：箱子」，存在 `provinggrounds-hud.json`。畫面太窄放不下時用原版排法、額外格子藏起來。墓碑畫面（使用者回饋後改）：左邊自己的背包畫面（含防具、特殊格、背包欄、副手、玩家模型）、右邊墓碑主人的背包畫面，位置固定（不跟 HUD 介面設定的箱子位置）。
- A7 配件排序：新工具 `tools/sort_shop_attachments.py` 從伺服器 tacz 槍械包讀每個配件的類型（index 的 type）寫進 shop.json 的 `atype`，再排序：瞄具 → 槍口 → 握把 → 槍托 → 彈匣 → 雷射 → 特殊彈藥 → 其他。瞄具倍率：紅點／全息（sight_*）當 1 倍排最前，其他用名稱上的倍率（可變倍率取最大，例如 4-10x = 10），名稱沒寫才用槍械包 display 的 zoom 最大值（TACZ 的 zoom 數字跟名稱倍率不一致，所以不優先用）；同倍率／同組依價格、名稱。商店「配件 → 全部」每組從新的一列開始，上面一列是組名與數量。「可裝手上的槍」變色照舊。
- A8 防具：商店只有皮革、鐵、鑽石、獄髓四種材質（沒有鎖鏈、金、海龜殼，所以海龜殼不用放；程式有預留鎖鏈與金，商店有就會出現）。防具頁改成 4 欄（材質）× 4 列（帽、胸甲、褲、靴），下面一列每欄一個「整套 $總價」按鈕，錢不夠顯示「還差 $N」並灰掉；整套 = 四件總和不打折，自由人八折照舊（`ArenaMode.buySet`，ArenaActionPacket 新增 BUY_SET）。單件照舊點格子買。
- F 穿牆擊殺：`core/Wallbang` 從擊殺者眼睛到被擊殺者身體中心做方塊碰撞檢查（只看碰撞箱），路上有不可穿透的方塊就算穿牆。可穿透 = TACZ 的子彈忽略標籤 `#tacz:bullet_ignore`（TACZ 預設：鐵柵欄、柵欄、柵欄門、樹葉；我們的槍械包 immersive_ballistic 把它清空了，所以以設定為主）＋伺服器設定 `wallbang_passable_blocks`（預設：#forge:glass、#forge:glass_panes、玻璃、玻璃片、#minecraft:leaves、鐵柵欄、#minecraft:fences、#minecraft:fence_gates、#minecraft:all_signs、#minecraft:wool_carpets、苔蘚地毯、雪片、蜘蛛網）。限制：用直線近似，不是子彈真正的彈道（遠距離下墜、跳彈、爆炸、擊殺者已經移動都可能不準；倒地後流血死亡用的是死亡當下的位置）。`KillNoticePacket` 的爆頭改成 1 byte 位元旗標（1 爆頭、2 穿牆），`KillFeedPacket`（大逃殺擊殺資訊）也加同樣的旗標。顯示：準星下方圖示變藍色「穿牆」＋小磚牆符號；團隊模式擊殺紀錄在武器圖示旁畫小磚牆；大逃殺擊殺資訊在名字後面加藍色 ▦（爆頭 ◎）。客戶端設定 `kill_icon_wallbang` 可關。網路版本這版已經是 23。
- E 團隊模式倒地：大廳對戰設定多一列「倒地 開／關」（只有管理員能改；預設值是伺服器設定 `[arena] downed_enabled_v1` = false）。共用類別：新的 `core/DownedCore`（倒地效果、解除、準心判斷，大逃殺也改用它）、`modes/br/BRDowned`（兩邊共用的「是不是倒地」，擋物品／回血／趴下）、`special/ActionLock`、`events/DownedEvents`。團隊模式專用的流血／扶起在 `modes/arena/ArenaDowned`（大逃殺的復活牌、祭壇、座椅、急救針自救這些只有大逃殺有，沒有搬過來）。數值沿用大逃殺：倒地血量、流血速度、扶起秒數、扶起範圍、扶起後血量。致命傷時同隊還有站著的隊友才倒地（槍王孤狼直接死）；倒地顯示「擊倒」；最終死亡（流血、再被打死、佔點全隊倒地）時用 GENERIC_KILL＋擊倒者當來源走一般死亡流程，擊殺、金錢、分數、槍王晉級都在這時候才算；被扶起不算。佔點全隊都倒地或死亡 → 倒地的人立刻全部死亡（每 0.5 秒檢查）。槍王晉級時倒地者也會換武器（原本就會發給活著的隊員）。客戶端：自己倒地時身上有「倒地」效果（擋輸入）；別人看到趴下用 ProneManager 的同步名單。扶起進度、流血秒數顯示在快捷欄上方小字。**沒有兩人實測**。
- D 掉線分身：`core/DisconnectBodies`（離線狀態存在 SavedData `provinggrounds_offline`）＋ `DecoyEntity` 的分身模式（不動、不消失、血量與額外生命值同掉線瞬間、真的受傷與死亡、掉線時倒地就趴著流血）。共用入口（不需要玩家物件）：`BattleRoyaleMode.onBodyKilled`／`offlineEliminate`（統計、擊殺、擊殺紀錄、墓碑用 `Tombstones.placeOffline`、整隊檢查）、`ArenaMode.handleBodyDeath`（死亡數、擊殺、金錢、分數、槍王晉級；`KillEvents.arenaKillOffline`）。各模式：大逃殺分身被殺＝淘汰（沒有復活牌，跟以前掉線一樣），回來只能旁觀且背包清空；團隊死鬥／槍王分身被殺＝死一次，回來後在死亡位置旁觀倒數再重生；佔點分身被殺＝本回合陣亡。分身還活著時回來：回到分身的位置與血量（大逃殺倒地的人回來仍是倒地；團隊模式回來是站著的）。超時 `disconnect_timeout`：大逃殺現在也用這個設定（視為淘汰、物品進墓碑），團隊模式照舊移出並清掉分身。大逃殺分身也會受圈外傷害。通知小字：掉線、回來、掉線過久被移出。比賽結束／重置時 `GameManager.reset` 清掉全部。**做不到／不同的地方**：(1) 隊友不能扶起倒地的分身（照計畫書的退路：分身倒地流血計時、不能扶）；(2) 伺服器重啟：比賽本身在開服時一律重置回大廳（原本的崩潰恢復規則），所以分身與離線狀態也會清掉，不會恢復；(3) 敵方重生區的防蹲點懲罰沒有套用到分身；(4) 大逃殺掉線時身上帶的隊友復活牌，分身被殺時會掉在分身位置（跟一般死亡一樣）。迷你死鬥、大廳、訓練場、跑庫塔不產生分身（只有大逃殺與團隊模式比賽中才會）。飛機上掉線照舊直接淘汰。
