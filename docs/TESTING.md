## v0.39.0（52 棟無木箱建築＋物資點緊貼掩體）

### 建築目錄與 24 棟新建築（J1～J2）
- **J1 目錄總數與 UI**：拿建築產生器右鍵打開「建築風格總覽」，確認 8 種風格都能選取且總數為 **52 棟**（現代/工業/日式/科幻各 7 棟、公共/中世紀/沙漠/海事各 6 棟），滾動捲軸無跑版。
- **J2 新建築實地生成**：每種風格挑至少 1 棟新建築（例如 `mod_fire_station`、`ind_train_depot`、`jp_dojo_compound`、`sci_radar_array`、`civ_grand_library`、`med_fortified_abbey`、`des_caravanserai`、`mar_cargo_freighter`）放置於測試場，確認：
  1. 完全沒有任何木箱（`CHEST`/`TRAPPED_CHEST`/`BARREL`）出現，也沒有新增電梯；
  2. 多層樓間皆為寬樓梯且終點切齊樓板、上下順暢；
  3. 天花板／屋內燈光足夠，不暗到伸手不見五指；
  4. 玻璃板、鐵欄杆、石牆與樓梯轉角都有正確自動連接。

### 室內物資點貼近掩體（J3～J4）
- **J3 新舊建築走廊檢核**：走進既有高走廊建築（如 `tactical_hq`、`shopping_mall`、`hospital`、`high_school`、`airport_terminal`、`logistics_mega`）以及新建築內部走廊／大廳，確認物資點（生於地上的戰利品／標記點）不再卡在走廊正中央，而是貼在牆邊、柱子、櫃台或室內掩體旁。
- **J4 門口不被擋住與數量保留**：確認進門通道與樓梯上下口沒有被物資點或吸附邏輯擠塞，並可用大逃殺搜索／地圖掃描確認物資總點數維持各棟標示數量。

### 半磚平滑移動與平地等速（K1～K3）
- **K1 半磚高低坡度平順**：依序鋪設「平地 → 下半磚 → 上半磚」、「平地 → 下半磚 → 完整方塊」與「平地 → 單塊下半磚 → 平地」來回走、跑與靜走，確認第一人稱視角平滑上下不跳格、下坡不短暫懸空。
- **K2 半磚與平地同速**：直線通過連續半磚階梯（26.6° 與 45° 接縫）對比平坦地面，感受 3D 前進速度、腳步聲與鏡頭晃動節奏一致；在平坦大面積半磚地板上移動則保持原本平地速度。
- **K3 子彈與雙層牆體不受影響**：對著半磚掩體邊角射擊確認子彈仍受完整碰撞阻擋；上方仍有實心方塊蓋住的半磚（如牆內縫隙）不會產生斜坡切角。

## v0.38.2（各刀破玻璃時機、樓梯與平地等速、攀爬放慢與方向取消、決賽圈擴大）

- [ ] **I1 快刀與重武器破玻璃時機貼合揮刀命中幀：** 分別拿出手速快的刀（例如匕首／爪刀）與前搖較長的近戰武器，對準玻璃、玻璃片或鐵欄杆按下左鍵輕擊與右鍵重擊 → 玻璃都在**刀刃真正揮到目標的那一幀**才碎裂，各自依照該武器本身的攻速與冷卻節奏運作，不再提早於點擊瞬間碎掉或受統一固定冷卻卡住。
- [ ] **I2 剛切刀還沒拔出前不會破玻璃：** 剛從其他格子切換到近戰武器、拔刀動畫還沒結束時馬上狂點左／右鍵對準玻璃 → 拔刀還沒完成前不會打破玻璃；拔刀完成後的下一刀才會正常打碎。
- [ ] **I3 揮刀中途切走物品會取消破玻璃：** 拿前搖較長的武器揮刀後、還沒到命中幀前馬上切到別格物品 → 不會隔空把玻璃打破。
- [ ] **I4 賽後玻璃與鐵欄還原：** 用各種近戰武器打碎大廳或大逃殺建築內的玻璃、玻璃片與鐵欄杆後結束一場比賽（或重開一局）→ 所有打破的玻璃與鐵欄杆仍正常自動還原並接回鄰居形狀。
- [ ] **I5 樓梯移動速度與平地完全相同：** 找一段長樓梯（含室內僅 2 格淨高的樓梯間與轉角平台），分別進行「直上、直下、斜走、橫著沿階梯走、靠牆側邊走平台」的步行與疾跑 → 所有方向的移動速度感、視野晃動與腳步聲節奏都和在一般平地上完全相同（上樓／下樓不會變快約 41%，橫走與平地平台也不會變慢），下樓依然每一階都貼地走過不跳階。
- [ ] **I6 攀爬動作放慢 100%（2 倍時間）＋按後／左／右往該方向取消：**
  - 大逃殺中跳起再按空白鍵翻爬高台 → 整體攀爬動畫與上升速度明顯放慢一半（全程約 1.1 秒），第一人稱雙手撐起與第三人稱動作一致放慢。
  - 攀爬中途按下 `S`（後退）、`A`（左）或 `D`（右）→ 立刻中斷攀爬並朝按下方向推離牆面落下，同時立即恢復自由移動並重新舉回手上槍械或刀械；若原本按著 `W+A` 斜跳開始攀爬，不會在剛抓牆瞬間誤取消。
- [ ] **I7 大逃殺決賽圈半徑擴大為 7.5 格（直徑 15 格）：**
  - 執行 `/pg circle` → 顯示 `決賽圈（7.5 格）停留 ... 秒`。
  - 大逃殺打到最後一階段進入決賽圈（或快速方案縮到決賽圈）→ 毒圈會停在半徑 `7.5` 格大小等待決賽圈倒數秒數，之後再縮到 0。

  - 跑步上長樓梯 → 速度明顯減緩 **30%**（不閃爍視野也不中斷奔跑）。
