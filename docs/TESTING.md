# 遊戲內測試步驟（v0.11.0）

這份清單用來在**正式伺服器與客戶端**上逐項確認功能。每一項都寫了「怎麼做」和「應該看到什麼」，照著打勾就好。

> **只想測這次修改的部分：** 看下面的「v0.11.0 重測項目」，其他段落是完整清單。

---

## v0.11.0 重測項目（約 25 分鐘）

**跳傘（已改成原版鞘翅）**

- [ ] **R-1 跳出就滑翔：** 飛機上按空白鍵 → 跳出後直接是原版鞘翅滑翔（胸甲欄是「跳傘鞘翅」，拿不下來）。
  - 提示顯示「鞘翅滑翔｜按 空白鍵 開傘（離地 50 格自動開傘）」。
- [ ] **R-2 手動開傘：** 滑翔中按空白鍵 → 開傘，鞘翅消失，下降變慢、WASD 控制方向。
- [ ] **R-3 不能回去：** 開傘後再按空白鍵 → 沒反應，不能收傘、不能回到鞘翅。
- [ ] **R-4 自動開傘：** 另一局一直滑翔不按 → 離地約 50 格時自動開傘，畫面提示「降落傘已自動打開」。
- [ ] **R-5 落地：** 落地（包含落在樹葉上）→ 沒有摔傷、身上沒有殘留鞘翅；接著可以趴下（Z）。
- [ ] **R-6 撞牆：** 滑翔撞到山壁 → 不會受傷。
- [ ] **R-7 祭壇復活（兩人）：** 復活後一樣是鞘翅滑翔 → 開傘 → 落地才拿到基礎裝備。

**趴下**

- [ ] **R-8 趴下姿勢：** 在大廳或落地後按 Z → 第三人稱（F5）看得到人物趴下、第一人稱鏡頭變低；再按 Z 站起來。
  - 手上拿著槍時也要正常（以前會被 TACZ 蓋掉）。
- [ ] **R-9 樹葉上：** 站在樹葉上按 Z → 可以趴下，不會顯示「空中不能趴下」。

**快捷欄、背包、輪盤**

- [ ] **R-10 槍歸位：** 用滑鼠把第 1 格的槍拖到背包或第 6 格 → 出現提示，而且槍**自動回到第 1 格**（不是留在游標上）。
- [ ] **R-11 專用格圖示：** 按 E → 快捷欄第 1～5 格空著時有淡淡的圖示（第 1、2 格步槍、第 3 格手槍、第 4 格十字、第 5 格手榴彈）；鎖住的背包格有鎖頭。
- [ ] **R-12 db_short：** 拿到 db_short（短管雙管霰彈槍）→ 進第 3 格（手槍格）。
- [ ] **R-13 輪盤：** 落地後身上有兩種以上補品 → 按住 4 會出現補品輪盤；按住 5 出現投擲物輪盤。
- [ ] **R-14 背包立刻生效：** 在箱子畫面用 Shift＋左鍵拿背包 → 不用關掉畫面，背包格的鎖頭立刻消失。

**墓碑**

- [ ] **R-15 不噴裝（兩人）：** 被淘汰 → 地上沒有噴出物品，死亡位置出現墓碑。
- [ ] **R-16 拿取（兩人）：** 另一位玩家右鍵墓碑 → 打開「<名字> 的墓碑」，裡面是死者身上全部物品（含背包）；拿東西一樣照快捷欄規則放。
- [ ] **R-17 拿空消失：** 把墓碑拿空後關掉畫面 → 墓碑消失。
- [ ] **R-18 一局結束：** 一局結束後 → 地圖上所有墓碑都被清掉。

**其他**

- [ ] **R-19 介面中不能移動：** 打開物品欄、箱子、地圖、選單時按 WASD → 人物不會動。
- [ ] **R-20 縮圈：** 開局後第一次縮圈的等待時間比之前多 1 分鐘；圈外每秒扣血約為之前的一半（第 1 階段每秒 1 點）。
- [ ] **R-21 管理工具分頁：** 創造模式「PG 管理工具」分頁裡有：所有工具、數據看板、四種箱子、祭壇、三種背包。

**新的管理工具**（`/pg give tool all` 會拿到全部）

- [ ] **R-22 刪除生成點：** 站在生成點旁邊右鍵「箱子生成點刪除工具」→ 刪掉最近的一個，那個位置閃紅色方框 3 秒、冒煙；聊天欄顯示座標與剩下幾個。
  - 16 格內沒有生成點時提示「附近 16 格內沒有箱子生成點」。
- [ ] **R-23 箱子轉換：** 右鍵「箱子轉換工具」→ 出現地圖清單 → 點一張地圖 → 按確認 → 聊天欄出現轉換進度與結果（跟 `/pg loot import` 一樣）。
  - 沒選地圖直接按確認 → 有提示音、不執行；按取消 → 關閉。
- [ ] **R-24 地圖繪畫：** 右鍵「地圖繪畫工具」→ 選地圖 → 確認 → 開始重新繪製地圖圖片（跟 `/pg map render` 一樣）。
- [ ] **R-25 權限（兩人）：** 一般玩家用這三個工具 → 只出現「沒有權限」。

- 沒寫「需要兩人」的項目，一個人就能測。
- 標「（兩人）」的項目需要第二個帳號或朋友。
- 有問題時，記下是第幾項、看到什麼（截圖最好），回報給我。

## 0. 準備（約 5 分鐘）

- [ ] **0-1 版本：** 伺服器的 `mods` 與客戶端的 `mods` 裡都只有 `provinggrounds-0.11.0.jar`（舊版已在 `mods-backup`）。
- [ ] **0-2 進得去：** 啟動伺服器 → 客戶端連線，能正常進入大廳。
  - 如果被擋在外面、顯示版本不符：兩邊的 jar 版本不一樣。
- [ ] **0-3 權限：** 你的帳號是 OP（測管理工具要用）。
- [ ] **0-4 測試局的開法（後面會用到）：**
  - 單人：主選單（預設 M 鍵）按大逃殺開始，或輸入 `/pg br start 1`（1 是地圖編號）。
  - 單人局要等你被淘汰才會結束，可以用 `/kill` 或走到圈外加速。
  - 中途要停：`/pg br stop`。
  - 創造模式下快捷欄與背包規則不會生效，**測 B1～B3 時請用生存或冒險模式**（開局會自動設成冒險模式）。

## B1 跳傘（約 5 分鐘）

開一局，在飛機上：

- [ ] **1-1 跳出：** 快捷欄上方提示「按 空白鍵 跳傘」。按空白鍵 → 立刻跳出飛機，直接進入原版鞘翅滑翔。
- [ ] **1-2 自動跳：** 另開一局都不按 → 飛到航線尾端會自動跳出。
- [ ] **1-3 鞘翅：** 胸甲欄是「跳傘鞘翅」，按 E 打開物品欄拿不下來。
- [ ] **1-4 開傘：** 按空白鍵，或離地約 50 格時自動 → 開傘，鞘翅消失，下降變慢、WASD 控制方向。
- [ ] **1-5 不能回去：** 開傘後再按空白鍵沒反應。
- [ ] **1-6 落地：** 落地（含樹葉上）→ 沒有摔傷，身上沒有殘留鞘翅。
- [ ] **1-7 空中限制：** 空中按趴下（Z）沒反應；落地後可以趴下。
- [ ] **1-8 斷線：** 跳傘中斷線再登入 → 身上沒有殘留鞘翅。

## B2 快捷欄規則與輪盤（約 10 分鐘）

落地後找箱子：

- [ ] **2-1 大型槍：** 從箱子 Shift＋左鍵拿大型槍（步槍、衝鋒槍等）→ 自動進第 1 格；第二把進第 2 格。
- [ ] **2-2 第三把大型槍：** 再 Shift 拿第三把 → 拿不起來，畫面出現「無法拿取兩把以上的大型槍（可用替換的方式拿取）」。
  - 連點也只會 1 秒提示一次。
- [ ] **2-3 互換：** 用滑鼠左鍵拿起箱子裡的槍（游標拿著）→ 點自己第 1 格的槍 → 兩把互換。
  - 換下來的槍在游標上，可以放回箱子。
- [ ] **2-4 手槍：** 手槍自動進第 3 格；第二把手槍拿不起來並提示。
- [ ] **2-5 槍放錯地方：** 用滑鼠把槍拖到第 6 格、背包、副手 → 都會彈回原位，並提示「槍只能放在快捷欄第 1～3 格…」。
- [ ] **2-6 其他放法：** 用數字鍵、F 鍵把槍換到別處 → 一樣不行。
- [ ] **2-7 專用格：** 把其他物品（例如彈藥）放進第 1～5 格 → 彈回並提示專用格。
- [ ] **2-8 補品：** 拿兩種不同的醫療品 → 一種在第 4 格，另一種進背包（要先有背包，見 B3）。
- [ ] **2-9 背包已滿：** 沒有背包時再拿第二種醫療品 → 拿不起來，提示「背包已滿，無法拿取」。
- [ ] **2-10 投擲物：** 手榴彈、煙霧彈同理，用第 5 格。
- [ ] **2-11 地上撿：** 把槍丟在地上（Q）再走過去撿 → 一樣照上面的規則放。
- [ ] **2-12 短按：** 短按 4 → 只是切到第 4 格（原版行為）。
- [ ] **2-13 補品輪盤：** 身上有兩種以上補品時，**按住 4** 約 0.25 秒 → 畫面中央出現補品輪盤，顯示每一種的圖示與總數。
  - 滑鼠指向一種、放開 4 → 那一種換到第 4 格並切過去。
  - 按住時可以用 WASD 走路，視角不會轉。
- [ ] **2-14 投擲物輪盤：** 按住 5 → 投擲物輪盤，操作同上。
- [ ] **2-15 倒地時（兩人）：** 被打倒地後按住 4 → 不會開輪盤。
- [ ] **2-16 管理員不受限：** 在大廳、或切成創造模式 → 槍可以隨便放，不受規則限制。

## B3 背包（約 5 分鐘）

- [ ] **3-1 背包欄：** 開局後按 E → 副手格正上方有一個「背包欄」（空的時候有淡淡的背包圖示）。
  - 主背包 27 格全部蓋灰色，放不進去、點不動。
- [ ] **3-2 一級背包：** 從箱子拿到一級背包 → 自動裝上；最下面一排前 5 格解鎖。
- [ ] **3-3 二、三級：** 拿到二級 → 10 格；三級 → 15 格。
  - 換上高級背包時，舊背包掉在腳邊。
- [ ] **3-4 同級或更低：** 再撿同級或更低級的背包 → 拿不起來並提示「已經裝著同等級或更高級的背包」。
- [ ] **3-5 背包放錯地方：** 背包拖到其他格 → 彈回並提示。
- [ ] **3-6 拿下背包：** 在背包裡放幾個物品 → 用滑鼠把背包從背包欄拿下來 → 被鎖住格子裡的物品自動搬到還開著的格子，放不下的掉在腳邊（**物品不能消失**）。
- [ ] **3-7 淘汰：** 被淘汰時背包跟其他物品一起收進墓碑（不會噴在地上）。
- [ ] **3-8 登出登入：** 對局中登出再登入 → 背包欄和解鎖格數不變。
- [ ] **3-9 下一局：** 下一局開始時沒有背包（全鎖）。

## B4 本場數據（約 5 分鐘）

- [ ] **5-1 自動開啟：** 一局結束（單人局：自己被淘汰）→ 自動開啟「本場數據」畫面，內容有：
  - 上方：結果（例如「紅隊 獲勝」或「本局結束」）、獲勝玩家、本場時間。
  - 中間 7 張卡片：本場 MVP、最高擊殺、最高助攻、最高傷害、最長存活、扶起隊友、祭壇復活。沒有人符合的顯示「無」。
  - 下方排行表：自己那一列是黃色底。
- [ ] **5-2 不能移動：** 畫面開著時按 WASD，人物不會動（開任何介面都不能移動）。
- [ ] **5-3 自動關閉：** 被送回大廳時畫面自動關閉；也可以按 Esc 或「關閉」。
- [ ] **5-4 聊天欄：** 有一段精簡版亮點，加上一行「你的成績：第 N 名｜擊殺…」。
- [ ] **5-5 重看：** 在大廳輸入 `/pg result` → 重新開啟同一份數據，數字跟剛才一樣。
  - 用非 OP 帳號也能用這個指令。
- [ ] **5-6 並列（兩人）：** 兩人擊殺一樣多 → 「最高擊殺」兩個名字都列出。
- [ ] **5-7 離線（兩人）：** 對局中有人斷線 → 排行表裡他的名字後面標「（離線）」。

## B5 數據看板（約 5 分鐘）

- [ ] **6-1 放置：** 創造模式「PG 管理工具」分頁找到「數據看板」，放在大廳 → 方塊上方浮空顯示「大逃殺數據｜個人」。
  - 內容有你的名字、等級、場數、勝場、擊殺…，數字要跟 B4 打完的結果一致。
- [ ] **6-2 面向玩家：** 繞著看板走 → 文字一直面向你；走遠超過約 32 格就看不到。
- [ ] **6-3 切換畫面：** 右鍵看板 → 切到「全服排行」；再右鍵 → 切回個人。
- [ ] **6-4 換排序：** 在全服排行畫面蹲下＋右鍵（手上不要拿東西）→ 排序依序換成勝場 → 擊殺 → K/D → 等級 → 助攻。
- [ ] **6-5 各看各的（兩人）：** 兩人站在同一個看板前，一人切換 → 另一人的畫面不變；兩人看到的「個人數據」都是自己的。
- [ ] **6-6 一般玩家（兩人）：** 一般玩家（非 OP、生存模式）打不掉看板，也放不了看板。
- [ ] **6-7 自動更新：** 打完一場回來，站在看板前約 10 秒內數字更新。
- [ ] **6-8 重啟：** 重啟伺服器後看板和數字都還在。

## B6～B10 管理員工具（約 10 分鐘）

先輸入 `/pg give tool all` 拿到五個工具，或在創造模式分頁「PG 管理工具」裡找。

**浮空文字**

- [ ] **7-1 建立：** 右鍵「浮空文字工具」→ 出現輸入畫面。
  - 用中文輸入法打「&6歡迎來到 Proving Grounds」→ 按確認或 Enter。
  - 頭上方出現金色文字。繞著走，文字一直面向你。
- [ ] **7-2 貼上：** 輸入畫面也可以用 Ctrl+V 貼上文字。
- [ ] **7-3 空白：** 什麼都不打直接確認 → 不建立。
- [ ] **7-4 重啟後仍在：** 重啟伺服器後文字還在。
- [ ] **7-5 開局不被清掉：** 文字放在地圖範圍內，開一局再結束 → 文字沒有被清掉。

**刪除與復原**

- [ ] **7-6 刪最近的：** 建立 3 段文字，站在其中一段旁邊右鍵「清除浮空文字工具」→ 刪掉的是最近那一段。
  - 聊天欄顯示「已刪除浮空文字：…（距離 N 格）」。
- [ ] **7-7 附近沒有：** 附近 16 格內沒有文字時右鍵 → 提示「附近 16 格內沒有浮空文字」。
- [ ] **7-8 依序復原：** 連刪 3 段，右鍵「復原刪除文字工具」3 次 → 依「最後刪的先回來」恢復，位置、顏色都跟原本一樣。
- [ ] **7-9 復原用完：** 第 4 次 → 提示「沒有可復原的浮空文字」。
- [ ] **7-10 指令版：** 刪一段後重啟伺服器，再輸入 `/pg text undo` → 也能復原（紀錄存在存檔裡）。

**箱子生成點**

- [ ] **7-11 新增：** 在地圖範圍內右鍵「箱子生成點放置工具」→ 「已新增箱子生成點（地圖 #N，X, Y, Z），目前共 M 個」。
- [ ] **7-12 重複：** 同一格再按一次 → 「此處已有箱子生成點…，未重複放置」，總數不變。
- [ ] **7-13 範圍外：** 在地圖範圍外按 → 提示不在地圖範圍內。
- [ ] **7-14 對局中：** BR 進行中按 → 提示不能新增。
- [ ] **7-15 顯示：** 右鍵「箱子生成點顯示工具」→ 「已顯示 N 個…」，附近的點出現黃色方框，可以穿牆看到。
  - 再右鍵 → 隱藏。
- [ ] **7-16 即時更新：** 顯示中新增一個點 → 方框立刻出現；用 `/pg loot remove` 刪掉 → 方框立刻消失。
- [ ] **7-17 只有自己看得到（兩人）：** 另一位玩家看不到方框。

**權限**

- [ ] **7-18 一般玩家（兩人）：** 一般玩家（非 OP、生存模式）用任何一個工具 → 只出現「沒有權限」，沒有任何效果。
