# 遊戲內測試步驟（v0.21.0）

這份清單用來在**正式伺服器與客戶端**上逐項確認功能。每一項都寫了「怎麼做」和「應該看到什麼」，照著打勾就好。

> **只想測這次修改的部分：** 看下面的「v0.14.0 重測項目」。之前的「v0.11.0 重測項目」和後面的完整清單仍可參考，但跳傘的部分以這次為準。

---

## v0.21.0 重測項目（約 5 分鐘，需要一個非管理員帳號）

- [ ] **Z-1 F3 只限管理員：** 一般玩家按 F3 沒有除錯畫面（看不到座標），F3＋B（碰撞箱）、F3＋G（區塊邊界）也沒效果；管理員照常可以用。
- [ ] **Z-2 進階顯示：** 一般玩家按 F3＋H 後，物品說明還是不會出現物品 ID 和耐久數字。
- [ ] **Z-3 替換特殊物品：** 特殊物品欄已經有東西時，在箱子（或墓碑）裡 Shift＋左鍵另一個特殊物品 → 兩個互換（原本的放回箱子那一格）；在物品欄畫面用滑鼠拿一個特殊物品點特殊物品欄 → 互換，換下來的可以丟掉或放進箱子。
- [ ] **Z-4 創造模式的兩格：** 創造模式打開物品欄，選「物品欄」分頁（箱子圖示）→ 盔甲欄右邊有特殊物品欄（上）和背包欄（下）；放進去、拿出來都正常，關掉再打開還在，切回生存模式也還在。

## v0.20.0 重測項目（約 10 分鐘）

- [ ] **Y-1 特殊物品模式開關：** 大廳選單左欄多一個「特殊物品：開／關」（管理員可以按）；也可以用 `/pg special mode on` 或 `off`。關閉時：箱子不出特殊物品、按 Q 提示「特殊物品模式已關閉」、快捷欄右邊與物品欄裡的特殊物品格都不顯示。
- [ ] **Y-2 背包放物品欄：** 撿到比身上低級（或同級）的背包 → 放進物品欄（第 6～9 格或背包裡），可以丟給隊友；撿到更高級的 → 自動換上，舊的放進物品欄。
- [ ] **Y-3 擊退盾減速：** 舉著擊退盾時走路、跑步都比平常慢（約 -25%）。
- [ ] **Y-4 防具 Shift 穿戴：** 防具放在背包裡，打開物品欄按 Shift＋左鍵 → 直接穿上（那個部位沒有穿東西時）。
- [ ] **Y-5 影響自己與隊友：** 擊退風暴彈、震爆地雷、地雷、燃燒地雷、致盲珠、毒氣彈，自己和隊友在範圍內也會受影響；擊退盾的衝撞不會傷到自己和隊友。
- [ ] **Y-6 擊退盾外觀：** 擊退盾拿在手上跟原版舉盾一樣（第一人稱、第三人稱都是），不是橫著拿。
- [ ] **Y-7 創造模式：** 創造模式物品欄裡的「Proving Grounds」分頁，有所有特殊物品、擊退盾、復活牌、背包、箱子、工具。
- [ ] **Y-8 特殊物品快捷欄：** 特殊物品模式開啟時，原版快捷欄右邊（隔一小段）多一格，顯示特殊物品；格子上方小字提示「[Q] 使用」；舉著擊退盾時是「[Q] 衝撞」、傳送珠飛行中是「[Q] 傳送」。
- [ ] **Y-9 殘影分身被打：** 打掉別人的分身 → 自己發光 3 秒，所有人都看得到（不上地圖）。

## v0.19.0 重測項目（約 15 分鐘，需要 2 個人，最好不同隊）

- [ ] **W19-1 第一次縮圈前沒有白牆：** 開局落地後，第一次縮圈開始前：畫面上看不到白牆、大地圖／小地圖沒有白圈、站在遠處也不扣血；淺藍色的下一圈照常顯示。縮圈一開始，白牆和白圈馬上出現，圈外開始扣血。
- [ ] **W19-2 飛機上第三人稱：** 登機後所有人（含管理員）自動變成第三人稱；跳出飛機後自動回到第一人稱。
- [ ] **W19-3 飛機上的隱形：** 飛機上敵人完全看不到（人、護甲、手上的槍都看不到）；隊友看得到彼此半透明；飛機上**所有人**的名條都看不到，跳傘後才看得到隊友名條。
- [ ] **W19-4 隱形沒有跑步粒子：** 用 `/effect give <名字> minecraft:invisibility 30` 讓一個人隱形後疾跑：另一隊的人看不到他、看不到腳下的粒子，但聽得到腳步聲。
- [ ] **W19-5 跳機後 2 秒：** 跳出飛機後約 2 秒內仍然隱形、不會受傷、不能攻擊；之後恢復正常。
- [ ] **W19-6 登機 5 秒不能跳：** 登機後快捷欄上方顯示「5 秒後可跳傘」倒數，期間按空白鍵沒反應；倒數完變回「按 空白鍵 跳傘」。
- [ ] **W19-7 第一人稱鎖定：** 一般玩家（非管理員）在大廳和對局中按 F5 都沒反應；管理員可以正常切換。
- [ ] **W19-8 副手：** 用 F 鍵、在物品欄點副手格、拖曳到副手格、游標指著格子按 F，都放不進副手；創造模式硬放進去的會在下一刻回到背包。
- [ ] **W19-9 煙霧彈消散聲：** 煙霧彈結束時的消散聲比之前小（約一半），其他聲音不變。

### v0.19.0 移動方式與腳步聲

- [ ] **M-1 自動奔跑：** 按 W 往前走就自動奔跑（不用按疾跑鍵）；開槍、瞄準、吃東西、蹲下時不會自動跑。
- [ ] **M-2 靜走：** 按住 Shift 走路明顯變慢，腳步聲變小；放開恢復。
- [ ] **M-3 蹲下：** 按 Ctrl 蹲下（扶隊友也是蹲下，所以現在是按 Ctrl 扶人）。
- [ ] **M-4 腳步聲大小：** 請另一個人在旁邊聽：奔跑的腳步聲比以前大、比較遠也聽得到；靜走很小聲。
- [ ] **M-5 材質分辨：** 在金屬、玻璃、木頭、石頭、草地、羊毛上跑，聲音差異比原版明顯（金屬玻璃清脆、木頭低沉、草地沙地悶、羊毛幾乎沒聲音）。
- [ ] **M-6 按鍵可改：** 按鍵設定裡有「靜走」（Proving Grounds 分類），原版「潛行」是 Ctrl，「疾跑」沒有綁定；都可以自己改。
- [ ] **M-7 方向性音訊：** 新版第一次開遊戲後，選項 → 音效設定 →「方向性音訊」是開著的（戴耳機測：閉眼聽別人在前、後、左、右、上、下走路，方向比以前好分辨）。自己關掉後再開遊戲不會被打開。
- [ ] **M-8 精準命中：** 對著一個站著不動的人，瞄準他身體前面一點點的空氣（胸口前方約半格）開槍 → 不會中彈（以前會中）；瞄準身體、手、腳、頭 → 都會中彈。蹲下的人也一樣。趴下、游泳的人照舊。

### v0.19.0 特殊物品（第四份計畫書 B、C、D）

> **測試小幫手（管理員）：** `/pg special list` 列出全部物品 ID；`/pg special give <ID>` 給自己一件（直接放進特殊物品欄）；
> `/pg special simulate 1000` 模擬開 1000 箱看出現幾件。創造模式的管理員在對局外也能使用特殊物品（方便單人測試），
> 但偵測器類需要有「別隊的存活參賽者」才有目標，建議 2～3 人分不同隊一起測。

**欄位與規則**
- [ ] **X-0 按鍵：** 新版第一次開遊戲後，到 選項 → 控制 → 按鍵設定 確認：使用特殊物品 Q、丟棄 G、切換射擊模式 B、倍鏡倍率 V、趴下 C、物品欄 Tab、靜走 Shift、潛行（蹲下）Ctrl、疾跑不綁定；另外 TACZ 匍匐沒有綁鍵、TACZ 近戰 F、玩家列表 `（數字 1 左邊）、主副手交換沒有綁鍵。之後自己改的按鍵，再開遊戲不會被改回去。
- [ ] **X-1 特殊物品欄：** 物品欄畫面裡，背包欄正上方多一格（空著時有淡淡的星形）。只有特殊物品放得進去。
- [ ] **X-2 其他格子拒收：** 對局中把特殊物品拖到快捷欄、背包、副手、箱子 → 會被彈回並提示；Shift 點箱子裡的特殊物品 → 自動放進特殊物品欄；欄位已經有東西 → 拿不走並提示。
- [ ] **X-3 使用鍵：** 按 **Q** 使用特殊物品欄的物品，用完就消失；欄位空的時候提示「特殊物品欄是空的」。按鍵設定裡可以改（名稱「使用特殊物品」）。
- [ ] **X-4 箱子出現率：** 開大約 10 個箱子會看到 1 件左右（低、中、高、空投都一樣）。
- [ ] **X-5 墓碑：** 帶著特殊物品死亡 → 物品在墓碑裡，別人可以拿走（會自動進他的特殊物品欄）。

**動作鎖定**
- [ ] **X-6 倒地：** 不能開槍（**特別確認槍真的打不出去**）、不能左右鍵用物品、不能放置／破壞方塊、不能開箱子；**可以**開背包、丟東西（G）、撿東西、切換快捷欄、按 Q 用特殊物品。
- [ ] **X-7 隱形斗篷：** 用了之後 5 秒內：不能開槍、不能用補品／投擲物、不能開箱子、不能按 Q；可以移動、撿東西、丟東西；移動比平常快。

**引擎**
- [ ] **X-8 發光提示：** 被任何偵測器照到的人，快捷欄上方會出現提示，寫明是「只有發光」還是「連地圖都顯示」。
- [ ] **X-9 地圖紅點：** 強力發光的目標在小地圖與大地圖上是閃爍的紅點。
- [ ] **X-10 衝擊波：** 被震飛、扣血（越靠中心越多），之後視角會亂晃約 10 秒，快結束時晃得越來越小；施放者和隊友不受影響。

**34 個物品（每個用一次看效果）**
- [ ] **X-11 致盲珠：** 前方推出一團黑霧（穿牆），被碰到的人看不見 5 秒。
- [ ] **X-12 腎上腺素：** 15 秒內跑得明顯變快；拿刀也一樣快（不會更快）。
- [ ] **X-13 隱形斗篷：** 5 秒內別隊看不到你（含裝備、手上的槍），跑步沒有粒子；隊友看到半透明。
- [ ] **X-14 彈簧鞋：** 朝看的方向衝出去（往上看就往上彈），落地不摔傷。
- [ ] **X-15 偵測器（5、6、7、19、20、21 號）：**
  - 簡略的敵人偵測器、敵人偵測器：隨機一名敵人發光＋上地圖，只有你看得到。
  - 敵人偵測器加強版：一整隊敵人發光＋上地圖，你的整隊都看得到。
  - 簡略的爆破敵人偵測器：隨機一名敵人發光，所有人都看得到，不上地圖。
  - 爆破敵人偵測器：隨機一名敵人發光＋上地圖，所有人都看得到。
  - 爆破敵人偵測器加強版：一整隊敵人發光＋上地圖，所有人都看得到。
- [ ] **X-16 臨時雪牆：** 丟出雪球，飛過的地面 0.5 秒後升起最高 4 格的雪牆，15 秒後消失。
- [ ] **X-17 擊退盾：** 第一次按 Q：手上那格換成盾（一直舉著、不能切換快捷欄、不能丟），前方的子彈被擋下、盾扣耐久；再按一次 Q：往前衝，撞到人／牆／衝到底就放衝擊波，然後盾消失、原本那格的東西回來。盾使用中倒地或死亡 → 原本的東西也會先回來。
- [ ] **X-18 擊退風暴彈：** 丟出去，落地處產生衝擊波。
- [ ] **X-19 假箱（3 種）：** 在面前放一個跟真箱一模一樣的箱子；任何人（包含自己、隊友）打開 → 扣 10 血、發光 5 秒、視角晃 5 秒，假箱消失。
- [ ] **X-20 地雷（4 種）：** 只有自己和隊友看得到（藍／棕／橘／白的小地毯）；敵人走到 2 格內，0.5 秒後：
  - 偵查地雷：附近敵人發光＋上地圖（你看得到）。
  - 地雷：爆炸，附近所有人（含自己人）扣血＋緩速。
  - 燃燒地雷：附近所有人每秒被燒 6 血，持續 5 秒。
  - 震爆地雷：衝擊波。
- [ ] **X-21 信號槍：** 全體收到「有人發射了信號槍」，你的位置上空掉下一個空投（地圖上看得到）。
- [ ] **X-22 煙幕彈：** 自己周圍 3 格冒出煙霧（跟煙霧彈一樣的煙）。
- [ ] **X-23 不死圖騰：** 15 秒內副手出現不死圖騰；這段時間受到致命傷 → 不倒地也不死；15 秒後圖騰消失。
- [ ] **X-24 護盾泡泡：** 15 秒內第一次被打 → 那一下完全沒扣血，血條多一段黃色（額外生命值，不會消失），並加速 10 秒。
- [ ] **X-25 傳送珠：** 丟出去直直飛（不會往下掉）；再按一次 Q 或飛到 35 格／15 秒 → 傳送到它正下方的地面；中途撞牆就在牆前傳送；不會摔傷。
- [ ] **X-26 靜音靴：** 15 秒內走路、跑步、落地、游泳都沒有聲音；開槍照樣有聲音。
- [ ] **X-27 毒氣彈：** 丟出去形成綠色毒氣 10 秒；裡面的敵人：畫面變成馬賽克、不定時咳嗽（視角先往上再往下猛點）、不定時被強迫往某個方向走、中毒；離開後再持續 5 秒。
- [ ] **X-28 急救針：** 蹲下扶隊友讀條時按 Q → 隊友立刻站起來、滿血；自己倒地時按 Q → 10 秒讀條（不能移動），完成後自己站起來、滿血；讀條中被打 → 中斷，針沒有消耗。
- [ ] **X-29 護甲修復包：** 身上所有護甲耐久變滿。
- [ ] **X-30 強化護甲修復包：** 護甲耐久變滿，而且耐久上限變多（每用一次再 +50%）。
- [ ] **X-31 圈外庇護：** 15 秒內在圈外不扣血，而且在圈外跑得比較快。
- [ ] **X-32 雷達脈衝：** 你腳下出現一圈往外擴散的綠色環；40 格內的敵人發光＋上地圖 3 秒（只有你看得到，被掃到的敵人不會收到提示）。
- [ ] **X-33 假槍聲：** 準星指的地方連續傳出約 6 秒的槍聲（用你手上那把槍的聲音），有一點火花，沒有傷害。
- [ ] **X-34 殘影分身：** 出現一個跟你一樣（皮膚、護甲、手上的槍）的人往前跑 10 秒，遇到 1 格高的方塊會跳；打一下就冒煙消失；你和隊友看到它有淡色輪廓。
- [ ] **X-35 每場結束：** 一局結束後地雷、假箱、分身、雪牆、毒氣、煙霧全部消失，身上的特殊效果也消失。

## v0.18.0 重測項目（約 15 分鐘）

- [ ] **V-1 空投標記：** 大地圖、小地圖上的空投標記變小（約原本的 1/3）。
- [ ] **V-2 空投外觀：** 空投箱（掉落中與落地後）是橄欖綠鋼框軍用補給箱：側面有橘黃警示條紋、頂面有吊帶十字與白色標記。
- [ ] **V-3 輪盤取消使用：** 正在吃補品或按住投擲物時長按 4（或 5）→ 動作被中斷（投擲物不會被丟出），輪盤開著時不能使用物品。
- [ ] **V-4 近戰格：** 第 3 格只能放近戰武器（格子圖示是刀）；手槍和其他槍都放第 1、2 格。
- [ ] **V-5 隨機近戰：** 開局時身上沒有近戰武器 → 第 3 格自動有一把隨機近戰武器；有自己帶的就用自己的。
- [ ] **V-6 受傷指示器：** 紅色細長方形貼著螢幕邊緣：沿邊緣比原本長（125%）、往內比原本薄（75%）、更不透明。
- [ ] **V-7 最終圈：** 最後一階段縮到一個點（半徑 0），所有人都會在圈外。
- [ ] **V-8 縮圈速度：** 圈移動得比之前慢（原本的 75%）。
- [ ] **V-9 箱子數量：** 地圖上大約 65% 的生成點有箱子（之前是一半）。

## v0.17.0 重測項目（約 10 分鐘）

- [ ] **U-1 鞘翅抬頭：** 滑翔時往上抬頭 → 最高只到水平線下 15 度（比上一版更低）。
- [ ] **U-2 近戰速度：** 手上拿匕首、爪刀、棒球棍或 CS2 刀具 → 跑的速度跟原版一樣（不會再多 20%）；換成其他東西變回原版的 80%。
- [ ] **U-3 指北針：** 沒有黑色底、貼齊螢幕最上方、比之前窄一點矮一點；三角形和角度數字在方位條下方。
- [ ] **U-4 自動補位（補品）：** 第 4 格放一個急救包、背包裡放同一種急救包 → 拿著第 4 格用完 → 背包裡那一疊自動補到第 4 格。
- [ ] **U-5 自動補位（投擲物）：** 第 5 格手榴彈丟完 → 背包或第 6～9 格同一種手榴彈自動補上。
- [ ] **U-6 不同種不補：** 背包裡只有別種急救包 → 用完後第 4 格維持空的（可以用長按 4 的輪盤自己選）。

## B6～B10 管理員工具（約 10 分鐘）

先輸入 `/pg give tool all` 拿到五個工具，或在創造模式分頁「PG 管理工具」裡找。

**浮空文字**

- [ ] **7-1 建立：** 右鍵「浮空文字工具」→ 出現輸入畫面。
  - 用中文輸入法打「&6歡迎來到 Proving Grounds」→ 按確認或 Enter。
  - 頭上方出現金色文字。繞著走，文字一直面向你。
- [ ] **7-2 貼上：** 輸入畫面也可以用 Ctrl+V 貼上文字。
- [ ] **7-3 空白：** 什麼都不打直接確認 → 不建立。
- [ ] **7-4 重啟後仍在：** 重啟伺服器後文字還在。
- [ ] **7-5 開局不被清掉：** 文字放在地圖範圍內，開一局再結束 → 文字沒有被清掉。

**刪除與復原**

- [ ] **7-6 刪最近的：** 建立 3 段文字，站在其中一段旁邊右鍵「清除浮空文字工具」→ 刪掉的是最近那一段。
  - 聊天欄顯示「已刪除浮空文字：…（距離 N 格）」。
- [ ] **7-7 附近沒有：** 附近 16 格內沒有文字時右鍵 → 提示「附近 16 格內沒有浮空文字」。
- [ ] **7-8 依序復原：** 連刪 3 段，右鍵「復原刪除文字工具」3 次 → 依「最後刪的先回來」恢復，位置、顏色都跟原本一樣。
- [ ] **7-9 復原用完：** 第 4 次 → 提示「沒有可復原的浮空文字」。
- [ ] **7-10 指令版：** 刪一段後重啟伺服器，再輸入 `/pg text undo` → 也能復原（紀錄存在存檔裡）。

**箱子生成點**

- [ ] **7-11 新增：** 在地圖範圍內右鍵「箱子生成點放置工具」→ 「已新增箱子生成點（地圖 #N，X, Y, Z），目前共 M 個」。
- [ ] **7-12 重複：** 同一格再按一次 → 「此處已有箱子生成點…，未重複放置」，總數不變。
- [ ] **7-13 範圍外：** 在地圖範圍外按 → 提示不在地圖範圍內。
- [ ] **7-14 對局中：** BR 進行中按 → 提示不能新增。
- [ ] **7-15 顯示：** 右鍵「箱子生成點顯示工具」→ 「已顯示 N 個…」，附近的點出現黃色方框，可以穿牆看到。
  - 再右鍵 → 隱藏。
- [ ] **7-16 即時更新：** 顯示中新增一個點 → 方框立刻出現；用 `/pg loot remove` 刪掉 → 方框立刻消失。
- [ ] **7-17 只有自己看得到（兩人）：** 另一位玩家看不到方框。

**權限**

- [ ] **7-18 一般玩家（兩人）：** 一般玩家（非 OP、生存模式）用任何一個工具 → 只出現「沒有權限」，沒有任何效果。
