這份清單用來在**正式伺服器與客戶端**上逐項確認功能。每一項都寫了「怎麼做」和「應該看到什麼」，照著打勾就好。

## 計畫書 5（v0.25.0）重測項目

> 這一段是這次的新內容，先測這段。AF-7（防蹲點）已經改版，以這裡的 P5-24～P5-26 為準。
> 新指令：`/pg arena debug addkills <red|blue|隊伍名> <N>`、`setmoney <玩家> <N>`、`skipstage`（團隊死鬥跳階段）、`skipround`（佔點結束回合）、`advance <隊伍名>`（槍王晉級）、`speed <倍率>`（對戰計時加速，這場有效）。

**互動鍵 F 與準星（所有模式）**

- [ ] **P5-1 拿槍開鏡不開門：** 拿槍、準星對著門按住右鍵開鏡 → 門不會動；對著物資箱、墓碑、祭壇開鏡 → 都不會被打開。
- [ ] **P5-2 F 開門：** 準星對著門按一下 F → 門只開（或關）一次；再按一下 → 切換一次。活板門、柵欄門、按鈕、拉桿也一樣。
- [ ] **P5-3 F 開箱：** 拿槍時對著物資箱、墓碑按 F → 打開；空手時右鍵和 F 都能打開。
- [ ] **P5-4 F 不會放方塊：** 手上拿著方塊或補品，對著地板按 F → 不會放出方塊、不會使用物品。
- [ ] **P5-5 互動提示：** 準星指著門 →「F 開關」、箱子／墓碑 →「F 開啟」、祭壇 →「F 復活」、倒地隊友 →「F 扶起」（準星下方小字）；開鏡時不顯示（按 F 仍有效）。在按鍵設定把互動改成別的鍵 → 提示跟著改。
- [ ] **P5-6 扶人：** 大逃殺隊友倒地，靠近按一下 F（不用蹲、不用按住）→ 讀條自動跑完扶起。讀條中：走出扶起範圍、開槍、吃補品、丟投擲物、用特殊物品（Q）、被打 → 各自中斷並顯示「讀條中斷，再按 F 重新開始」，再按 F 可以重來。
- [ ] **P5-7 祭壇：** 身上有隊友復活牌時，在祭壇旁按一下 F（或空手右鍵祭壇）→ 自動讀條；中斷條件同 P5-6（走出祭壇範圍會顯示「離開祭壇範圍」）。蹲下已經不會啟動祭壇。
- [ ] **P5-8 點狀準心：** 空手、拿槍時準星都是一個小點；開鏡時照 TACZ 原本的樣子。客戶端設定 `[hud] crosshair_dot = false` → 空手恢復原版十字（拿槍的準星改在 TACZ 自己的設定裡改）。
- [ ] **P5-9 按鍵：** 第一次開新版 → 互動是 F、TACZ 槍托近戰改成 X；之後自己改的不會被蓋掉。
- [ ] **P5-10 管理工具：** 管理員拿管理工具右鍵 → 照舊能用。

**提示不擋視野**

- [ ] **P5-11 標題改到上方：** 開局倒數、倒地、淘汰、扶起、勝負、團隊死鬥換階段、佔點回合預告 → 都不在畫面中央，改成畫面上方一行小字（半透明底）、約 3 秒淡出；新的直接蓋掉舊的。
- [ ] **P5-12 戰鬥中畫面：** 團隊死鬥／佔點／大逃殺戰鬥中截圖，準星周圍只有互動小字和擊殺小圖示。

**擊殺提示**

- [ ] **P5-13 擊殺圖示：** 擊殺敵人 → 準星下方彈出小小的「╳ 擊殺」約 1 秒；爆頭是金色「爆頭」；連殺 2 以上顯示「N 連殺」，3 以上變紅色。大逃殺也有。
- [ ] **P5-14 擊殺音效：** 擊殺有鈴聲＋經驗聲＋短金屬聲，連殺越多音越高；爆頭多一聲更亮的鐘聲。`[hud] kill_sound = false` 或音量 0 → 沒聲音。
- [ ] **P5-15 擊殺紀錄：** 團隊死鬥／佔點／槍王之王、迷你死鬥 → 右上角顯示「擊殺者 [武器圖示] 被擊殺者」，爆頭多一個 ◎，約 5 秒淡出，最多 5 行。
- [ ] **P5-16 迷你死鬥連殺：** 在迷你死鬥連殺 10 人以上後被殺 → 全服聊天欄「○○ 的 N 連殺被 ○○ 終結了！」並播號角聲。

**新模式整合規則**

- [ ] **P5-17 重生倒數：** 團隊死鬥、槍王之王死亡 → 在死亡位置旁觀，動作欄「3 秒後重生」，3 秒後回重生點。佔點照舊（回合中旁觀到下一回合）。
- [ ] **P5-18 重生保護：** 重生後 5 秒內被打不會扣血、自己近戰打人也打不出傷害；一開槍保護就結束。
- [ ] **P5-19 轉帳：** 轉帳沒有冷卻，可以連續轉。
- [ ] **P5-20 特殊物品：** 大廳團隊模式設定裡有「特殊物品 開／關」；開的時候擊殺敵人會掉一個特殊物品；商店裡沒有特殊物品。
- [ ] **P5-21 地圖：** 團隊模式中沒有小地圖、大地圖、方位條；回大廳後恢復原狀。
- [ ] **P5-22 槍械放置：** 商店買的槍、槍王之王每階段的槍放在哪一格（回報給我）；背包格全部都能用（沒有背包鎖定）。
- [ ] **P5-23 掉線：** 對局中離線再於 5 分鐘內回來 → 照原本的隊伍、金錢、職業繼續。離線超過 5 分鐘（測試可把 `disconnect_timeout` 改成 20 秒）→ 隊友聊天欄「○○ 因掉線過久被移出」，之後回來只能旁觀。

**防蹲點改版**

- [ ] **P5-24 範圍與警告：** 走到敵方重生點水平 18 格內 → 動作欄「敵方重生區！N 秒後開始受傷」，畫面四周紅色細框閃爍；2 秒後開始每秒扣血 2、7、12、17…（上限 100），變慢、發光；走出去就歸零。
- [ ] **P5-25 紅色邊界：** 從外面接近敵方重生區（範圍外 10 格內）→ 自己附近出現一段半透明紅色弧形牆；範圍外 5 格內畫面上方小字「前方是敵方重生區」。自己隊的重生區不顯示。`[hud] anti_camp_wall = false` 就不畫。
- [ ] **P5-26 多重生點（選測）：** 在伺服器設定 `[arena] red_spawns_extra` 加座標 → 紅隊重生時隨機選一個，每個點都有自己的防蹲點範圍與紅色邊界。

**佔點視覺提示**

- [ ] **P5-27 光柱：** 戰鬥開始後，從基地就能看到開放據點的一道細光柱（穿牆可見）；無人＝白、紅領先＝紅、藍領先＝藍、兩隊都在點上＝黃色閃爍。兩個據點同時開放時各一道。
- [ ] **P5-28 字母與距離：** 光柱底部上方有「A 35m」之類的字；據點在視野外時，畫面左右邊緣有「◀ A」或「B ▶」。
- [ ] **P5-29 範圍框：** 地面有據點範圍的方框，站進去變粗。未開放的據點不畫。`[hud] dom_beacon = false` → 全部不畫。

**槍王之王晉級**

- [ ] **P5-30 多餘擊殺：** 倍率 1、單人隊伍，用 `/pg arena debug addkills <名字> 3` → 每個 tick 晉級一階，連升 3 階（擊殺不會被吃掉）。
- [ ] **P5-31 人數變動：** 3 人隊伍（門檻 3）中有一人掉線超過 disconnect_timeout 被移出 → 門檻變 2；若擊殺數已經 ≥ 2 立刻晉級。

**戰績面板**

- [ ] **P5-32 Caps Lock：** 團隊模式中按住 Caps Lock → 右側出現戰績（擊殺、死亡；團隊死鬥、佔點另外有金錢），放開就關。**請回報放開時面板有沒有馬上關掉**（Caps Lock 是鎖定鍵，有的電腦放開事件不可靠）；不可靠的話把客戶端 `[hud] scoreboard_toggle = true`（按一下開、再按一下關），或在按鍵設定把「戰績面板」改綁其他鍵。

**其他**

- [ ] **P5-33 小地圖自己：** 大逃殺小地圖、大地圖上自己的箭頭是綠色、有黑色外框。
- [ ] **P5-34 隊伍數 0：** 大逃殺大廳把隊數按「－」到「0 孤狼」→ 所有人都是孤狼；開局後勝利判定、側邊欄、沒有復活牌、小地圖沒有隊友、名條都正常。
- [ ] **P5-35 商店全槍：** 商店各槍械分類多了很多槍（總共 122 把），價格看 `docs/SHOP_PRICES.md`；舊版就有的 51 把價格不變。
- [ ] **P5-36 跑庫塔：** 管理員站在起點 `/pg parkour setstart`、站在終點壓力板上 `/pg parkour setend`、站在排行榜位置 `/pg parkour setboard`。玩家進跑庫塔場地 → 走出起點 3 格開始計時（動作欄秒數）→ 踩到終點 → 聊天欄顯示秒數並傳回大廳 (-4, 32, -1)；破個人最佳 → 全服公告＋音效、排行榜前 3 名更新。
- [ ] **P5-37 方塊還原（所有方塊）：** 大逃殺中在地圖裡打破玻璃片（槍打、手榴彈、RPG）、炸牆、打開箱子拿東西、放方塊 → 比賽結束回大廳時全部恢復：玻璃片和旁邊的玻璃重新連成一整片（不會變成一條一條）、牆補回、箱子內容恢復、放的方塊消失。聊天欄／日誌有「Block restore: N 個」。管理員 `/pg glass` 看目前記錄數量；`/pg glass record` 手動開始記錄、`/pg glass restore` 停止並還原（測試用）。
- [ ] **P5-38 平常改地圖不會被還原：** 沒有比賽時，管理員在地圖裡蓋東西、拆東西 → 下一場開始時不會被改回去（只有被子彈或爆炸打破的玻璃會修）。

## 團隊死鬥／佔點／槍王之王（新模式，約 30 分鐘，至少 2 個人）

管理員：M →「開始遊戲」→ 選模式（按下去就換成這個模式）→ 調設定 →「開始」。也可以用 `/pg arena start tdm|dom|gk`，`/pg arena stop` 強制結束，`/pg arena money <玩家> 1000` 給錢測商店。

**共用**

- [ ] **AF-1 選模式：** 「開始遊戲」裡四個模式都能點；目前的模式有「目前」標籤；非管理員只能看，不能換。
- [ ] **AF-2 設定：** 團隊死鬥可以調目標擊殺（±10）與時間（±1 分），佔點可以調目標分數（±100），槍王之王可以調擊殺倍率（±1）。團隊死鬥和佔點的隊伍固定是紅藍兩隊。
- [ ] **AF-3 分隊：** 沒選隊的人開局時自動補到人少的那隊；已經在紅藍隊的人不動。
- [ ] **AF-4 HUD：** 畫面中上有模式名稱、倒數、兩隊分數條；右下有金錢、職業、擊殺與死亡。
- [ ] **AF-5 丟東西：** 按丟棄（G）→ 東西馬上回到背包（佔點可以丟槍）。
- [ ] **AF-6 彈藥：** 背包一直有一個無限彈藥箱，拿到的槍是滿彈。
- [ ] **AF-7 防蹲點：** 走到敵方基地的羊毛上 → 紅字警告、變慢、跳不起來、發光、持續扣血。
- [ ] **AF-8 結束：** 比賽結束 → 標題顯示勝方，聊天欄有擊殺榜前三名，10 秒後全員清空背包回大廳。

**商店（M）**

- [ ] **AF-9 開商店：** 在自己基地按 M → 商店介面：左邊是分類，右邊是商品（圖示、名稱、價格）；滑鼠滾輪可以捲動。
- [ ] **AF-10 購買：** 錢夠的時候點商品 → 拿到物品並扣錢；錢不夠 → 紅字「金錢不足」；走出基地再買 →「必須在自己的基地內才能購買」。
- [ ] **AF-11 自由人：** 職業是自由人時，所有價格是八折。
- [ ] **AF-12 防具：** 買防具 → 直接穿上（原本那件放回背包）。
- [ ] **AF-13 職業：** 在「職業」分頁換職業 → 舊的起始槍和補品被換成新職業的。突擊兵有速度 II；哨兵蹲著不動時有抗性，而且每秒 +$1。
- [ ] **AF-14 轉帳：** 在「轉帳」分頁選金額（或「全部」）→ 點隊友旁的「轉帳」→ 雙方都收到訊息；45 秒內再轉 → 顯示冷卻。
- [ ] **AF-15 選單：** 商店左下的「選單」→ 打開大廳頁（管理員可以在這裡結束遊戲）。

**團隊死鬥**

- [ ] **AF-16 擊殺：** 殺敵 → 隊伍分數 +1、+$20；被殺 → +$15，重生在自己基地，補品和投擲物補滿。
- [ ] **AF-17 階段：** 時間過 1/3 → 標題「進入中期」、獎金 ×3；過 2/3 →「後期」×9；落後的隊伍每人 +$750／+$1500。
- [ ] **AF-18 勝負：** 先到目標擊殺數的隊伍贏；時間到時分數高的贏，同分平手。

**佔點**

- [ ] **AF-19 準備：** 開局（以及每回合之前）全員傳回基地、出口被屏障封住、標題顯示「第 N 回合」與本回合據點，據點地板變金磚。
- [ ] **AF-20 戰鬥：** 倒數結束 → 屏障拆掉；前 30 秒 HUD 顯示「佔領凍結」，站在點上不會有進度。
- [ ] **AF-21 佔領：** 只有一隊在點上時進度每秒 +1，兩隊都在 → 顯示「⚠爭奪中」、進度不動；進度到 13 → 佔領成功，本回合 +300 分。
- [ ] **AF-22 收入：** 站在開放的據點上每秒 +$2；回合結束時聊天欄顯示「本回合佔點收入」。
- [ ] **AF-23 陣亡：** 回合中被殺 → 變成旁觀，鏡頭跟著活著的隊友；按 Shift 換下一個隊友；下一回合才復活。
- [ ] **AF-24 全滅：** 一隊全部陣亡 → 另一隊贏本回合。
- [ ] **AF-25 回合獎金：** 勝方 $560，之後連勝遞減；敗方 $360，之後連敗遞增。金錢最多 $2500。
- [ ] **AF-26 首殺：** 每回合第一個擊殺 +$160，聊天欄有公告。
- [ ] **AF-27 勝負：** 先到目標分數（預設 1000）的隊伍贏。

**槍王之王**

- [ ] **AF-28 開局：** 所有人血量 100，防具都一樣（沒有防具、皮革、金或鐵其中一種，脫不掉），隨機出生在場地各處；手上是第一階段的武器，背包裡有配件、醫療包、彈藥箱。
- [ ] **AF-29 晉級：** 隊伍擊殺數達到「人數 × 倍率」→ 整隊換成下一階段的武器（舊的槍、配件、投擲物都會清掉），聊天欄公告。
- [ ] **AF-30 投擲物階段：** 投擲物用完 → 1 秒內補 1 個。
- [ ] **AF-31 獲勝：** 最後一階段（第 9 階段）完成擊殺數 → 「成為槍王！」。
- [ ] **AF-32 孤狼：** 沒分隊的人各自一隊，HUD 列表上顯示自己的名字。

## v0.23.1 重測項目

- [ ] **AE-1 空投：** 打開空投箱 → 一定有 1 把頂級槍（狙擊、重機槍或高級步槍）、2 件鑽石或獄髓防具、1 個背包（大多是三級）、2～3 個高級配件、2～3 個高級補品、1～2 個投擲物、很多子彈，特殊物品模式開著時還有 1 件特殊物品。也可以用 `/pg loot simulate airdrop 100` 看平均。
- [ ] **AE-2 不死圖騰：** 用了不死圖騰後受到致命傷 → 沒死、沒倒地，血量變 50、血條多 25 黃色、有恢復效果 10 秒；螢幕中間「不會」跳出圖騰動畫，有粒子、音效比原版小聲。
- [ ] **AE-3 消音器：** 被裝了消音器的槍打中時，紅色受擊指示器寬 3 倍（只知道大概方向）；沒裝消音器照舊。
- [ ] **AE-4 小地圖發現敵人：** 敵人在螢幕邊緣、很遠、只露一點點、或一閃而過時，小地圖不會標出來；把準星對著他、看清楚約半秒後才會標。蹲下的人 40 格、趴下的人 24 格外不會被標。
- [ ] **AE-5 全隊共用復活牌：** 三人隊，A 死掉、B 撿起 A 的復活牌 → 全隊收到提示；C（身上沒有牌）蹲在祭壇旁邊也能啟動祭壇復活 A；右上角「隊伍復活牌」數字全隊都看得到。
- [ ] **AE-6 縮圈時間：** 快速一場約 5 分鐘、標準約 12 分鐘、慢速約 20 分鐘。

## B1 跳傘（約 5 分鐘）

開一局，在飛機上：

- [ ] **1-1 跳出：** 快捷欄上方提示「按 空白鍵 跳傘」。按空白鍵 → 立刻跳出飛機，直接進入原版鞘翅滑翔。
- [ ] **1-2 自動跳：** 另開一局都不按 → 飛到航線尾端會自動跳出。
- [ ] **1-3 鞘翅：** 胸甲欄是「跳傘鞘翅」，按 E 打開物品欄拿不下來。
- [ ] **1-4 開傘：** 按空白鍵，或離地約 50 格時自動 → 開傘，鞘翅消失，下降變慢、WASD 控制方向。
- [ ] **1-5 不能回去：** 開傘後再按空白鍵沒反應。
- [ ] **1-6 落地：** 落地（含樹葉上）→ 沒有摔傷，身上沒有殘留鞘翅。
- [ ] **1-7 空中限制：** 空中按趴下（C）沒反應；落地後可以趴下。
- [ ] **1-8 斷線：** 跳傘中斷線再登入 → 身上沒有殘留鞘翅。

## B2 快捷欄規則與輪盤（約 10 分鐘）

落地後找箱子：

- [ ] **2-1 大型槍：** 從箱子 Shift＋左鍵拿大型槍（步槍、衝鋒槍等）→ 自動進第 1 格；第二把進第 2 格。
- [ ] **2-2 第三把大型槍：** 再 Shift 拿第三把 → 拿不起來，畫面出現「無法拿取兩把以上的大型槍（可用替換的方式拿取）」。
  - 連點也只會 1 秒提示一次。
- [ ] **2-3 互換：** 用滑鼠左鍵拿起箱子裡的槍（游標拿著）→ 點自己第 1 格的槍 → 兩把互換。
  - 換下來的槍在游標上，可以放回箱子。
- [ ] **2-4 手槍：** 手槍自動進第 3 格；第二把手槍拿不起來並提示。
- [ ] **2-5 槍放錯地方：** 用滑鼠把槍拖到第 6 格、背包、副手 → 都會彈回原位，並提示「槍只能放在快捷欄第 1～3 格…」。
- [ ] **2-6 其他放法：** 用數字鍵、F 鍵把槍換到別處 → 一樣不行。
- [ ] **2-7 專用格：** 把其他物品（例如彈藥）放進第 1～5 格 → 彈回並提示專用格。
- [ ] **2-8 補品：** 拿兩種不同的醫療品 → 一種在第 4 格，另一種進背包（要先有背包，見 B3）。
- [ ] **2-9 背包已滿：** 沒有背包時再拿第二種醫療品 → 拿不起來，提示「背包已滿，無法拿取」。
- [ ] **2-10 投擲物：** 手榴彈、煙霧彈同理，用第 5 格。
- [ ] **2-11 地上撿：** 把槍丟在地上（Q）再走過去撿 → 一樣照上面的規則放。
- [ ] **2-12 短按：** 短按 4 → 只是切到第 4 格（原版行為）。
- [ ] **2-13 補品輪盤：** 身上有兩種以上補品時，**按住 4** 約 0.25 秒 → 畫面中央出現補品輪盤，顯示每一種的圖示與總數。
  - 滑鼠指向一種、放開 4 → 那一種換到第 4 格並切過去。
  - 按住時可以用 WASD 走路，視角不會轉。
- [ ] **2-14 投擲物輪盤：** 按住 5 → 投擲物輪盤，操作同上。
- [ ] **2-15 倒地時（兩人）：** 被打倒地後按住 4 → 不會開輪盤。
- [ ] **2-16 管理員不受限：** 在大廳、或切成創造模式 → 槍可以隨便放，不受規則限制。

## B3 背包（約 5 分鐘）

- [ ] **3-1 背包欄：** 開局後按 E → 副手格正上方有一個「背包欄」（空的時候有淡淡的背包圖示）。
  - 主背包 27 格全部蓋灰色，放不進去、點不動。
- [ ] **3-2 一級背包：** 從箱子拿到一級背包 → 自動裝上；最下面一排前 7 格解鎖。
- [ ] **3-3 二、三級：** 拿到二級 → 14 格；三級 → 21 格（每一排都是左邊 7 格）。
  - 換上高級背包時，舊背包掉在腳邊。
- [ ] **3-4 同級或更低：** 再撿同級或更低級的背包 → 拿不起來並提示「已經裝著同等級或更高級的背包」。
- [ ] **3-5 背包放錯地方：** 背包拖到其他格 → 彈回並提示。
- [ ] **3-6 拿下背包：** 在背包裡放幾個物品 → 用滑鼠把背包從背包欄拿下來 → 被鎖住格子裡的物品自動搬到還開著的格子，放不下的掉在腳邊（**物品不能消失**）。
- [ ] **3-7 淘汰：** 被淘汰時背包跟其他物品一起收進墓碑（不會噴在地上）。
- [ ] **3-8 登出登入：** 對局中登出再登入 → 背包欄和解鎖格數不變。
- [ ] **3-9 下一局：** 下一局開始時沒有背包（全鎖）。

## B6～B10 管理員工具（約 10 分鐘）

先輸入 `/pg give tool all` 拿到五個工具，或在創造模式分頁「PG 管理工具」裡找。

**浮空文字**

- [ ] **7-1 建立：** 右鍵「浮空文字工具」→ 出現輸入畫面。
  - 用中文輸入法打「&6歡迎來到 Proving Grounds」→ 按確認或 Enter。
  - 頭上方出現金色文字。繞著走，文字一直面向你。
- [ ] **7-2 貼上：** 輸入畫面也可以用 Ctrl+V 貼上文字。
- [ ] **7-3 空白：** 什麼都不打直接確認 → 不建立。
- [ ] **7-4 重啟後仍在：** 重啟伺服器後文字還在。
- [ ] **7-5 開局不被清掉：** 文字放在地圖範圍內，開一局再結束 → 文字沒有被清掉。

**刪除與復原**

- [ ] **7-6 刪最近的：** 建立 3 段文字，站在其中一段旁邊右鍵「清除浮空文字工具」→ 刪掉的是最近那一段。
  - 聊天欄顯示「已刪除浮空文字：…（距離 N 格）」。
- [ ] **7-7 附近沒有：** 附近 16 格內沒有文字時右鍵 → 提示「附近 16 格內沒有浮空文字」。
- [ ] **7-8 依序復原：** 連刪 3 段，右鍵「復原刪除文字工具」3 次 → 依「最後刪的先回來」恢復，位置、顏色都跟原本一樣。
- [ ] **7-9 復原用完：** 第 4 次 → 提示「沒有可復原的浮空文字」。
- [ ] **7-10 指令版：** 刪一段後重啟伺服器，再輸入 `/pg text undo` → 也能復原（紀錄存在存檔裡）。

**箱子生成點**

- [ ] **7-11 新增：** 在地圖範圍內右鍵「箱子生成點放置工具」→ 「已新增箱子生成點（地圖 #N，X, Y, Z），目前共 M 個」。
- [ ] **7-12 重複：** 同一格再按一次 → 「此處已有箱子生成點…，未重複放置」，總數不變。
- [ ] **7-13 範圍外：** 在地圖範圍外按 → 提示不在地圖範圍內。
- [ ] **7-14 對局中：** BR 進行中按 → 提示不能新增。
- [ ] **7-15 顯示：** 右鍵「箱子生成點顯示工具」→ 「已顯示 N 個…」，附近的點出現黃色方框，可以穿牆看到。
  - 再右鍵 → 隱藏。
- [ ] **7-16 即時更新：** 顯示中新增一個點 → 方框立刻出現；用 `/pg loot remove` 刪掉 → 方框立刻消失。
- [ ] **7-17 只有自己看得到（兩人）：** 另一位玩家看不到方框。

**權限**

- [ ] **7-18 一般玩家（兩人）：** 一般玩家（非 OP、生存模式）用任何一個工具 → 只出現「沒有權限」，沒有任何效果。
